# What's new

What each release of kay and its libraries adds, newest first, each feature with where it is documented. kay and its libraries share one version, so one section covers them all; what a release breaks is in [Upgrading](upgrading.md).

## Unreleased

- kayjs-auth: the consent page, the token form and the lists of tokens and approved apps show a scope as the label the app words under `auth.scopes.<scope>` in its messages, its code without one ([kayjs-auth](../packages/auth/llms/oauth-server-and-tokens.md)).
- kayjs-auth: `passkeys: { rpName, userVerification }` names the site to the authenticator and sets how hard adding a passkey and a passkey second factor ask for a PIN or a biometric ([kayjs-auth](../packages/auth/llms/oauth-passkeys-two-factor.md#passkeys)).
- kayjs-auth: `guests: { maxAge: '30d' }` deletes the guests older than that who hold no session, calling `onDelete`; without it they are kept as before ([kayjs-auth](../packages/auth/llms/passwords-and-mails.md)).
- kayjs-auth: `githubProvider({ scopes: ['read:user', 'user:email'] })` reads the primary verified address off `/user/emails`, so a user hiding their email signs up with it; every provider preset takes `{ scopes, params }` and the self-hostable ones a base `url`, GitHub Enterprise's included, Discord's `apiBase` being `url` ([kayjs-auth](../packages/auth/llms/oauth-passkeys-two-factor.md)).
- `mcp: { path }` moves the MCP endpoint, and `openapi: { path, referencePath }` the OpenAPI document and its reference page, a path colliding with a page, an API route or `/_kay` stopping the server ([API routes](api-routes.md#openapi)).
- `store` in kay.config.ts, `sqliteData(path)` or `{ jobs, rates }`, is where every queue, locked schedule and rate limit naming no store keeps its jobs, locks and counts ([Background jobs](production.md#background-jobs), [Action protection](action-protection.md)).
- `cors` in kay.config.ts is the default rule of every API module that sets none, `api({ cors: false })` opting one out, and `api({ rateLimit })`, with `detail: { rateLimit, bodyLimit }` on a route, limits requests and bodies per module and per route ([API routes](api-routes.md#limits)).
- kayjs-ui: `toast.error(message, { duration })` sets how long a toast stays and `Infinity` keeps it until dismissed, the info toast takes `--color-kui-info`, and `--radius-kui-card` rounds buttons, cards and overlays as it rounds text fields ([kayjs-ui](../packages/ui/llms/basics.md)).
- kayjs-ui: `Segmented` and `Tabs` options take `icon` and `disabled` as `ChipGroup`'s do, `Select` options take `disabled`, and `BarList`, `MediaGallery` and `ScatterChart` name their no-data text `emptyLabel` ([kayjs-ui](../packages/ui/llms/tables-navigation-and-layout.md)).
- kayjs-ui: `variant` names a form and `tone` a meaning across `Button`, `IconButton`, `Menu`, `CopyButton` and `Notice` (`danger` replaces `error`), and `Button` takes `size` ([kayjs-ui](../packages/ui/llms/basics.md)).
- kayjs-ui: every disclosure takes `open` and `onOpenChange(open)`, in place of `onClose` and `onToggle` ([kayjs-ui](../packages/ui/llms/basics.md)).
- Site search ranks a word higher the more of its title or heading it makes up, leaves `button` labels out of the index but for a heading's own, and gives each hit `headingParts`, its heading with the words found marked ([Site search](sitemap-search-fonts.md#site-search)).
- kayjs-ui: `CommandPalette` with `siteSearch` marks the words found in each section's heading as in its line of text, both in the accent colour ([kayjs-ui](../packages/ui/llms/tables-navigation-and-layout.md)).
- A layout's `page` takes `noindex`, `revalidate` and `search` for every page under it, as it takes `security`, the innermost setting winning ([Page settings](routing.md#page-settings)).
- `seo.themeColor` sets every page's `theme-color`, a colour or a `{ light, dark }` pair written as one meta per colour scheme, without a `manifest` ([Head](head.md#give-every-page-a-title-template-and-a-social-card)).
- A page's `lastmod` setting, a `Date`, a date string or a function of each listed URL's params, adds `<lastmod>` to its entries in the sitemap ([Sitemap and robots.txt](sitemap-search-fonts.md#sitemap-and-robotstxt)).
- `robots: { disallow: ['/admin'] }` in `kay.config.ts` adds rules to the generated `/robots.txt`, listed in every locale and under the `base` with the `Sitemap:` line kept, and `robots: false` serves none ([Sitemap and robots.txt](sitemap-search-fonts.md#sitemap-and-robotstxt)).
- `publicCache: { '/fonts/**': '365d' }` in `kay.config.ts` has the browser keep the public files a glob names for that long instead of revalidating them on every visit ([Public files](styles-and-assets.md#public-files)).
- kayjs-cms words every text of the screens and the editor through the app's catalogs under `cms.<area>.<name>` keys before its English, the editor's forms reading them in the browser, so a site words the editor once in `src/messages/<locale>.ts` ([Texts and languages](../packages/cms/llms/words.md)).
- kayjs-ui looks every default text up in the app's catalogs under `ui.<component>.<prop>` keys before its English, so one block in `src/messages/<locale>.ts` words the whole library; CommandPalette's `recentLabel` is new, and chart and contribution dates follow the page's locale ([Texts and languages](../packages/ui/llms/words.md)).
- kay words what a visitor reads that it wrote, schema refusals by kind, protection refusals and the server error, through the app's catalogs under `kay.*` keys before its English, and `wording()` from `kay/words` is that lookup for libraries ([Texts from kay and its libraries](locales.md#texts-from-kay-and-its-libraries)).
- `navigate(href, { scroll: 'keep', transition: false })` and `data-keep-scroll` / `data-no-transition` on a link or an element around links swap a page without scrolling to the top or without a view transition ([Navigation](navigation.md)).
- `persisted(name, value, { maxAge: '30d' })` sets how long its cookie is kept, a year by default ([Islands](islands.md)).
- `kay dev --port`, or a `PORT` in the environment or `.env`, fails when the port is busy instead of moving to the next one ([Dev server](dev-server.md)).
- `kay new --runner <label>` names the runner label the scaffolded CI runs on ([Project](project.md)).
- kayjs-mail: `mailer({ smtp: { name, timeout, maxConnections, rateLimit } })` merges over the SMTP built from the environment, and `settings.logo` or a `Layout`'s `@header` puts a logo above the card ([kayjs-mail](../docs/src/content/docs/libraries/kayjs-mail.md#production-settings)).
- kayjs-cms: `cms({ uploads: { types, maxSize } })` sets the most an upload may weigh, `'50mb'` or bytes, 20 MB by default; the editor refuses a bigger file before sending it and the upload route reads that much whatever the app's `bodyLimit` ([kayjs-cms](../packages/cms/llms.txt)).
- `images.widths` sets the ladder of widths images resize to, `image(src, { quality })` one image's quality, and `images.quality` is documented as also the share cards' JPEG quality ([Images](images.md)).
- A relative image in a collection's Markdown body loads through `image()` with a `srcset` and `sizes`, an entry can set its own `slug` in its frontmatter, and `markdown: { highlight, headingLinks, readingSpeed }` in `kay.config.ts` sets Markdown's options once for every collection ([Content](content.md)).
- kay's cookies share one name style: the locale cookie is `kay_locale`, the old `kay-locale` still read, and `kay_flash` and `kay_locale` are set for the `base` path instead of the whole host ([Privacy](privacy.md#cookies)).
- `session({ sameSite: 'strict' | 'none' })` changes the session cookie's `SameSite`, `'lax'` by default, `'none'` always `Secure` ([Server](server.md#sessions)).
- An action's `rateLimit` takes `key: ctx => ...` to count a person, an account or a token instead of the client's address ([Action protection](action-protection.md#rate-limits)).
- `ask(messages, { tools: [addNote] })` lets a model call an app's actions: each runs as the visitor with its guards, validation and rate limits, a failure goes back to the model as an error result, a loop capped by `maxSteps` runs until it answers, and `reply.progress()` and `reply.calls` expose the calls, which `Chat` shows before the text of its turn when its action returns `.progress()` ([kayjs-ai](../docs/src/content/docs/libraries/kayjs-ai.md#let-the-model-call-your-actions)).
- `Chat(action={reply})` from `@kaynooo/kayjs-ai/chat.kay` is a chat island over a streaming action: history, the reply streaming in as markdown without images, pending and error states with a retry, Stop, kayjs-ui's look and keyboard and screen-reader use ([kayjs-ai](../docs/src/content/docs/libraries/kayjs-ai.md#a-chat-for-your-site)).
- `kay i18n translate <locale>` of `@kaynooo/kayjs-ai` fills the messages and localized entries a locale lacks with a model, keeping `{placeholders}` and plural forms, saved as drafts; `--dry-run` lists them and estimates the tokens; an entry is a draft through its `draft: '<field>'` field or a `# draft` line ([kayjs-ai](../docs/src/content/docs/libraries/kayjs-ai.md#translate-what-is-missing)).
- kayjs-auth: the `rules` option sets password and username lengths and a password check of the app's own, followed by the server, the prebuilt pages and `features().rules`, which an island passes to `passwordProblem` and `usernameProblem` ([kayjs-auth](../packages/auth/llms.txt)).
- kayjs-auth: `email.expires` sets how long each link and code works, and the mails state the real figure in the reader's language, with `expires` in a template's data ([kayjs-auth](../packages/auth/llms.txt)).
- kayjs-auth: a sign-in follows the `session()` plugin's `maxAge`, `absoluteMaxAge` and `browserMaxAge`, so the cookie and the list of sessions agree, and `sessionMaxAge`, `sessionAbsoluteMaxAge` and `browserSessionMaxAge` are gone; a magic link opened in another browser keeps the remember choice of the one that asked ([kayjs-auth](../packages/auth/llms.txt)).
- kayjs-auth: every time option takes seconds or a string such as `'30d'`: `rememberMaxAge`, `audit.maxAge`, `organizations.invitationMaxAge`, a limit's `window` and a token's `expiresIn` ([kayjs-auth](../packages/auth/llms.txt)).
- `ctx.locals.session.settings` gives the `maxAge`, `absoluteMaxAge` and `browserMaxAge` the `session()` plugin resolved, in seconds, for a library that follows the app's session ([Server](server.md)).
- kayjs-auth: `pages.home` is where every flow lands when nothing asked for another page, the mailed links, a code, registering, a passkey and a provider included, and the pages localize it ([kayjs-auth](../packages/auth/llms.txt)).
- kayjs-auth: "keep me signed in" gives one lifetime whatever way the visitor signs in, magic link, passkey and providers included, and `pages.remember` (`'checkbox'`, `'always'` or `'never'`) hides the box without replacing the page ([kayjs-auth](../packages/auth/llms.txt)).
- kayjs-cms: the file picker offers only the types `cms({ uploads })` takes, and a refused file says its type or size; kayjs-ui's `FileDrop` takes `onReject` for the dropped files `accept` leaves out, and takes a file with no browser-known type for the server to judge ([kayjs-cms](../docs/src/content/docs/libraries/kayjs-cms.md)).
- kayjs-mail: the mailer's `lang` is the locale a mail renders in when the message names none, and the `<html lang>` is the locale rendered, which `renderLocale()` from `kay/server` answers ([kayjs-mail](../docs/src/content/docs/libraries/kayjs-mail.md#the-recipients-language)).
- kayjs-mail: a mailer with a custom `transport` and no `from` or `SMTP_FROM` stops a production boot instead of sending from `kay@localhost` ([kayjs-mail](../docs/src/content/docs/libraries/kayjs-mail.md#other-transports)).
- `entry` in `kay.config.ts` names the server entry for every command, and `kay build --entry` is accepted without `--compile`, pointing its check step at that entry ([Project](project.md)).
- A `NODE_ENV` outside `development`, `production` and `test`, such as `staging`, warns once at boot that the production defaults are off ([Production](production.md)).
- `offline: false` is typed and turns the service worker off, `kay env` lists `KAY_SECRET`, and the rate-limit store, the millisecond units and `hydrate="load"` are stated as the code has them ([Offline](sitemap-search-fonts.md#offline), [Islands](islands.md#hydration)).
- The pages the offline worker keeps follow `trailingSlash`, and a visit to either form of a kept page finds its copy ([Offline](sitemap-search-fonts.md#offline)).
- Feed links and guids follow `trailingSlash`, matching each page's canonical URL ([Content](content.md)).
- `@kaynooo/kayjs-ai` calls an LLM with no SDK: `ask()` over Anthropic or any OpenAI-compatible server returns a reply that `await`s as the text and streams as snapshots into an `await` block or an action's answer, and `fakeAi` answers in development and tests (`kay add ai`, [kayjs-ai](../docs/src/content/docs/libraries/kayjs-ai.md)).
- `ai({ limit, budget })` in kayjs-ai caps the questions and the tokens a chat visitor, and all of them, may spend, refusing with a `limited` error; an action throwing an error that carries `Symbol.for('kay.refused')` answers its status with `Retry-After` instead of 500 ([kayjs-ai](../docs/src/content/docs/libraries/kayjs-ai.md#limit-what-visitors-spend), [Streaming actions](api-from-islands.md#streaming-actions)).
- An action returning a thenable async iterable, such as a model's reply, streams it instead of waiting for its end, and its call is typed as the stream ([Streaming actions](api-from-islands.md#streaming-actions)).
- An `await` block takes an async iterable, such as an async generator or a model's reply, and renders `then` again with each part it yields, on the server as the page streams and in an island ([A value that arrives in parts](rendering.md#a-value-that-arrives-in-parts)).
- The dev tool's drawer moves by its head, resizes by any edge or corner, and docks to the bottom or the right of the window, padding the page while open; the bar drags to any corner, and the layout is kept for the browser, so a new tab opens the tool as it was left ([Dev server](dev-server.md)).
- The dev tool's Images tab gives copies of one image drawn alike one row with their count, outlining each on hover, rounds the density to two decimals, no longer flags an SVG served under a name not ending in `.svg` as oversized, reading its content type off Resource Timing, and its panels wrap long values instead of scrolling sideways ([Dev server](dev-server.md)).
- The dev tool's Images, Env and Routes tabs draw their rows alike, Request, Head, Routes, Env and Images each have a filter, with a "Problems only" toggle on Head and Images; addresses, header and env values have copy buttons, the drawer's head copies the open tab as Markdown, a script or stylesheet a tab names opens in the editor as a `.kay` file does, and Request counts an error status ([Dev server](dev-server.md)).
- The dev tool has a Network tab: what the page fetched, its load and the last page swaps apart, each request with its kind (a page swap, an action, a server island, a fetch or a file), status, size and time, an error status counted on the tab ([Dev server](dev-server.md)).
- `Server-Timing` times the guards, the import of the page's modules and the loads as a whole too, and the dev tool's Request tab charts each phase ([Production](production.md), [Dev server](dev-server.md)).
- The dev tool's Islands tab gives each island's props size and how long it took to hydrate ([Dev server](dev-server.md)).
- `kay i18n missing` lists what each locale lacks, messages and localized entries; a message marked `// draft` is reported by `kay check` (`draft-message`, in the new `i18n` group) until `kay i18n accept <locale>` or a person deletes the comment; an extension adds commands to `kay` with `commands` ([Locales](locales.md#messages), [Extensions](component-libraries.md#extensions), [Commands](check-and-tools.md)).
- An action whose handler is an `async function*`, or returns any async iterable, streams each value to the island calling it: the call resolves with a typed `ActionStream` (`last()`, `status()`, `on()`, `close()`), the action's guards, schema, rate limits and cross-site check running first, while a plain form post and an MCP tool call get the last value and `site.call` every value ([Streaming actions](api-from-islands.md#streaming-actions)).
- A rate limit counts a weight: `limit.hit(key, undefined, tokens)` and a `RateStore`'s `hit(key, windowMs, weight)` add several at once, so `max` caps tokens or bytes rather than attempts ([Action protection](action-protection.md#limits-outside-an-action)).

## 1.51.2

- The dev tool is redrawn in kay's palette and mark, with an icon and a toned count on each tab, the rail folding to icons when narrow, and new layouts for Problems, Request, Head, Env, Images, Performance, Routes, i18n and Islands; a library's tab takes an `icon`, and `count` a `'warn'` tone, and the bar no longer shows the reload line ([Dev server](dev-server.md), [A tab for a library](component-libraries.md#a-tab-for-a-library)).
- `shareCard({ title, image })` takes an imported `.svg` as `image`, drawn to cover the card before the title, with its cards written by `kay build` and kept for an executable like `images.card.logo` ([Images](images.md#draw-a-share-card-for-a-page)).
- The dev tool's Images tab no longer flags an SVG as served more pixels than it is drawn with, as Chromium gives one without a size 150x150 and the same bytes draw at any size; an image whose address ends in `.svg` is exempt, a raster still is flagged ([Dev server](dev-server.md)).
- `kay check` and the editor warn of an `img` or `input(type="image")` with no `width` and `height`, which shifts the page as it loads (`unsized-image`, in the new `performance` group; [What `kay check` verifies](checks.md#what-kay-check-verifies), [Lints](lints.md)).
- A valueless Markdown component tag with no later `>` stays text inside a blockquote too, as outside one: the quote's `>` markers no longer count as its close ([Content](content.md#components-in-markdown)).
- A component reading a slot anywhere but as a bare `{slot}`, in an attribute, a ternary, an `if` test or an `if ... as` alias, hydrates on the server's markup instead of logging `island ... did not match its server markup` and rendering again, as kayjs-ui's `Table` with an `@empty` slot and no rows did.

## 1.51.1

- A kayjs-ui `Table` stacked as cards on a phone breaks a long value with no space, such as a file path, inside its card instead of widening the page, and its sort buttons are at least 2rem tall to tap ([Table](../docs/src/content/docs/libraries/kayjs-ui.md)).
- The dev tool's Problems tab has a Copy button that puts every listed problem on the clipboard as plain text, the page URL first, to paste into an LLM ([Dev server](dev-server.md)).
- A Markdown component tag kay cannot read, such as stray text after a JSON prop or a brace never closed, fails `kay check`, the build and `bodyHtml` with `markdown-invalid` at its line instead of reaching the page as text, as it did already broken, and a JSON prop nests to any depth ([Content](content.md#components-in-markdown)).
- The dev tool drawer keeps one height whatever its open tab, so switching tabs no longer moves its header and tab rail ([Dev server](dev-server.md)).
- Linting a `.kay` file no longer reports `no-nested-ternary` on a single ternary that reads a prop with a default: kay's read of the default adds no ternary a lint rule can see ([Linting](checks.md#linting)).

## 1.51.0

- `keslint --cache` lints every `.kay` file again after a kay upgrade, so findings a new kay adds show at once, and a lint message on a prop names it as the file writes it, not `__props.name` ([Checks](checks.md#linting)).
- With `mcp: true`, an API route is an MCP tool only when it opts in with `detail: { tool: true | 'description' | { name, description } }`, as an action does with `tool`: a route that does not stays in the OpenAPI document and an agent never finds it; `kay check` reports the routes relying on the old default (`deprecated-api-tool`) and a route setting both `hide` and `tool` (`hidden-tool`) ([API routes](api-routes.md#mcp), [upgrading](upgrading.md)).
- `toolCall(request)` from `kay/server` tells a hook registered before `pages()`, a guard or a handler that a request is a tool call `/mcp` dispatched, and which tool: a front guard lets a bearer key reach `/mcp` and its tools alone, with no knowledge of kay's action URLs ([API routes](api-routes.md#mcp)).
- kay type-checks with the stable TypeScript 7 compiler (`typescript` 7.0.x, installed under kay's own `typescript7` alias) instead of `@typescript/native-preview`, and its `tsgo` command stays: `kay` ships it, so a script running `tsgo` bare keeps working. An app declares nothing new: kay depends on `typescript` 6 itself, the package typescript-eslint reads, which `typescript` 7 no longer offers.
- kayjs-auth's OAuth server ends a refresh token family 90 days after its first token whatever its rotations (a token unused for 30 days is still refused), shows an approved app's last use as its last API call, and asks the user again when an app starts declaring `scopes` after approving a client while it declared none ([kayjs-auth](../packages/auth/llms.txt)).

Releases before 1.51 are in [What's new, older releases](whats-new-archive.md).
