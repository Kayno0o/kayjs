# Security policy

## Supported versions

Security fixes go into the latest minor release of kay and its libraries (kayjs-auth, kayjs-ui, kayjs-mail, kayjs-cms), as a patch. They all share one version, so upgrading to the latest one picks up every fix.

## Reporting a vulnerability

Please do not open a public issue. Report it privately instead:

- through [GitHub's private vulnerability reporting](https://github.com/Kayno0o/kayjs/security/advisories/new),
- or by email to contact@kaynooo.fr.

A useful report says:

- the package and version affected,
- what an attacker can do,
- the steps or the smallest app that reproduces it.

## What happens next

You get an answer once the report has been read. The fix is released as a patch, followed by a public advisory crediting you, unless you would rather not be named. Please keep the issue private until that advisory is out.
