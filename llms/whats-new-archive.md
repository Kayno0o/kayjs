# What's new, older releases

What each release before 1.54.1 added, newest first, each feature with where it is documented. The newer releases are in [What's new](whats-new.md); what a release breaks is in [Upgrading](upgrading.md).

## 1.54.0

- `kay dev` restarts once for a save written in place: a second file event for a file whose content it already took in triggers nothing ([kay dev](dev-server.md)).
- `kay dev` serves its first page about 40% sooner, on a third less CPU up to that page: the first server starts once `kay.config.ts` is read instead of after the `.kay/types` tree is written, which now follows when the server listens ([The dev server](dev-server.md)).
- A page ships only its own rules: one whose rules fit the inline limit no longer loads the whole stylesheet after the paint (a `media="print"` link and a `noscript` copy), so a site's first page weighs what it uses. The classes its islands set after load are counted, a production build warns with the island and the line of a class set from a value it cannot read, and Tailwind 4.1's `@source inline("...")` in the app's CSS keeps its classes on every page; `kay dev` logs a `[kay]` error when an element gets a class its page has no rule for ([Styles](styles-and-assets.md#link-or-inline-the-stylesheets)). A page rendered at build time keeps the rules of the classes it shows, and `lateStyles: true` in `kay.config.ts` loads the whole stylesheet after the paint as before.
- An island's script no longer carries the icons of a module it imports without using them, and an island calling `signal()` alone no longer loads the value encoder `persisted()` and action calls share: a site of a few islands and a dozen icons loses about 1.8 KB of brotli ([Images](images.md)).
- kayjs-ai's chat looks finished: `Chat` takes `greeting`, `suggestions` (questions an empty chat sends on a click), `toolLabels` (a reply's tool calls fold into one muted line such as `Searched the docs x2`) and `sendIcon`/`stopIcon`; `ChatLauncher` has a New conversation button and an Enlarge button in its panel header, a filled launcher button that turns into a close icon, a 36rem panel of a fixed height (`--kai-chat-height`, `--kai-chat-height-large`), and `--kai-chat-*` custom properties to theme it ([Chat island](../packages/ai/llms/chat.md#floating-chat)).
- A stream an action call returns to a handler inside a block that the call itself removes, such as a chat suggestion that sends and leaves, is no longer closed with that block: it lasts with the nearest owner still alive ([Streams from islands](api-from-islands.md)).
- kayjs-ai's chat highlights the code of an answer once a block is finished, on the server with the app's own `markdown.highlight` from `kay.config.ts`, and ships no highlighter to the browser; an action returning `.progress()` streams it, an app without a highlighter shows plain code as before ([Chat island](../packages/ai/llms/chat.md)).

## 1.53.3

- kayjs-ai's `ChatLauncher` puts the chat behind a button at the bottom right of every page, opening it in a panel whose JavaScript loads on the first open, keeping the conversation across page swaps and reloads of the tab; `Chat` takes `remember` and `links="here"` for it ([Chat island](../packages/ai/llms/chat.md#floating-chat)). The docs' chat moved from `/ask` to that button. Escape anywhere in a `Chat` stops a reply under way and prevents the event's default, so a dialog or panel around it stays open.
- The `Chat` island opens the links of a reply in a new tab, so following a source no longer swaps the page and drops the conversation ([Chat island](../packages/ai/llms/chat.md)).
- A page is prerendered when the module it imports holds an exported container the build cannot vouch for, as long as the page takes none of it: only the pages importing that export, or something built from it, stay per request. A list of objects such as `export const NAV = [{ id, label, icon }]` (imported icons allowed) read by `for item of NAV`, `NAV.map(item => item.id)` and the like, a constant read by a computed key, and a test that writes to a constant or uses `import * as` on an unrelated module no longer make a module state, and a constant exported by `export { X }`, `export { X as Y }` or `export default X` is judged like one exported where it is declared ([Prerendering](prerendering.md#prerendering)).

## 1.53.2

- A command refused for an option or argument it does not take prints its own usage line alone, `kay build: unknown option --no-chek, did you mean --no-check?` without `parseArgs`'s hint, and `kay build --no-cache` builds without reading what earlier builds left in `.kay/cache` ([Build and start](build-and-start.md)).
- A page importing `image`, `shareImage` or `shareCard` from `kay/image`, or whose layouts, components or modules do, is prerendered like one importing an image, instead of being rendered per request ([Prerendering](prerendering.md#prerendering)).
- A page importing an exported object or array literal of strings, numbers and booleans, such as `export const CONTACT = { email: '...' }`, is prerendered when no file of the project writes to it or hands it on, instead of treating it as module state ([Prerendering](prerendering.md#prerendering)).

## 1.53.1

- kayjs-ai asks the provider to cache the prompt by default, so a chat and each step of a tool loop stop paying full price for the system prompt, tools and history: Anthropic gets automatic `cache_control`, an OpenAI-compatible server a `prompt_cache_key` per conversation (dropped when it refuses it), `ask(..., { cache: false | '1h' })` changes it, `reply.usage` reports `cacheReadTokens` and `cacheWriteTokens`, and the token budget counts them ([prompt caching](../packages/ai/llms/asking.md#prompt-caching)).
- kayjs-ai streams from Mistral with only `AI_BASE_URL`, `OPENAI_API_KEY` and `AI_MODEL` set: a server refusing `stream_options` is asked again without it, array content keeps its text, and a stream ending on `error` fails the reply ([asking](../packages/ai/llms/asking.md)).
- `analytics({ provider: 'ga4', measurementId, apiSecret })` sends Google Analytics 4 page views from the server through its Measurement Protocol, with a visitor id made on the server and no cookie ([Privacy](privacy.md#count-visits-through-your-own-origin)).
- `consent` from `kay/analytics` reads and sets the visitor's analytics answer from an island or a server render, and `consent: { notice: false }` leaves the asking to the app's own banner ([Privacy](privacy.md#ask-for-analytics-consent-in-your-own-ui)).
- A `live: true` cached key refreshes its pages even when the replicas sharing a `CacheStore` run on machines whose clocks differ by a few seconds, once they have heard each other (half a second with `sqliteCache`), the store's `publish` relaying a clock reading ([cache stores](rendering.md#caching)).
- A page importing an `~icons/<set>/<name>` icon, or whose layouts, components or modules do, is prerendered like one importing an image, instead of being rendered per request ([Prerendering](prerendering.md#prerendering)).
- A page importing an `~icons/<set>/<name>` icon of an installed set, or whose layouts, components or modules do, is prerendered like one importing an image, instead of being rendered per request ([Prerendering](prerendering.md#prerendering)).
- The dev tool's Head, Images, Env and Not found tabs show their warning counts from the page load and after each page swap, without opening the tab ([dev tool](dev-tool.md)).
- A tab left open on a stopped `kay dev` server, or behind a proxy answering 502 for it, retries its events stream every five seconds after ten seconds down instead of four times a second, still meets a restart within a quarter second, and a hidden tab waits until it is shown ([kay dev](dev-server.md)).

Releases before 1.53.1 are in [What's new, older releases](whats-new-archive.md).

## 1.53.0

- A `resource()` reading a route whose handler reads a `live` cached key asks the route again after `invalidate`, with nothing written ([live data](api-from-islands.md#following-cached-values)).
- A collection with `live: true` shows an `invalidate()` or a CMS edit in every open page that read it ([content](content.md#drafts)).
- `followLog(() => list)` from `kay` keeps a log or chat list at its bottom while the reader is there and the first item showing in place when items load above ([Follow a log](navigation.md#follow-a-log)).
- `kay fmt --from-html [file]` prints HTML, from a file or stdin, as a formatted `.kay` template through the translation `kay migrate astro` uses, and the docs site converts a pasted snippet in the browser; the translation keeps a no-break space and writes `#[` in text as `\#[` ([kay fmt](check-and-tools.md), [Template lines](templates.md#write-html-and-convert-it)).
- `analytics()` from `kay/analytics` counts visits with Plausible, Umami, Simple Analytics or Matomo through the app's own origin, with no pasted script or CSP exception, page swaps counted, an optional consent notice and the visitor's address sent only where the provider needs it, plus Fathom, Cloudflare Web Analytics and any tracker script by `script` and `endpoint` ([Privacy](privacy.md#count-visits-through-your-own-origin)).
- `kay migrate astro` and `kay fmt --from-html` keep the space a line break makes between two inline siblings (`#[b a] #[i b]`) and comment out a web component's `<slot>` ([kay fmt](check-and-tools.md)).
- Redirects can be added while the site runs: `kay not-found --redirect /old --runtime` and kayjs-cms's missing pages screen write them to `data/not-found.sqlite`, which the server reads for a path no page serves; they stay on the site unless `runtimeRedirects.hosts` lists a host, and `kay check` reports a target nothing serves ([Redirects](routing-endpoints-and-base.md#redirects), [kayjs-cms](../packages/cms/llms.txt)).
- A page whose own rules weigh between half the inline limit and the limit keeps them inline instead of linking a stylesheet copy, which paints a first view sooner (`bun run bench:paint` measures it) ([Styles](styles-and-assets.md)).
- Redirects can be added while the site runs: `kay not-found --redirect /old --runtime` and kayjs-cms's missing pages screen write them (a 307, a 308 with kayjs-cms's Permanent box) to `data/not-found.sqlite`, which the server reads for a path no page serves; they stay on the site unless `runtimeRedirects.hosts` lists a host, and `kay check` reports a target nothing serves ([Redirects](routing-endpoints-and-base.md#redirects), [kayjs-cms](../packages/cms/llms.txt)).
- A tool's input schema, and the OpenAPI document, describe `s.Integer()` and `s.Numeric()` as a number alone, and a tool's schema no longer requires a field with a `default` ([tools](api-routes.md)).
- A stale tab believes the build the server named for 5 seconds, and a page an action post came back to as an error page (a 404, a guard's denial) carries `kay-posted` too, so a reload no longer posts it again ([a deploy under open tabs](production.md#a-deploy-under-open-tabs)).
- kayjs-ai: `kay i18n translate` holds a reply that reorders the tags of its source, and fails a source holding a tag it cannot read without asking the model ([translating](../packages/ai/llms/translating.md)).
- `kay check` reports an entry of a localized collection opening on a `# draft` line, as `kay i18n translate` writes one, with the `draft-entry` lint ([lints](lints.md)).
- `kay i18n translate` writes the plural forms the locale picks between (`few`, `many`...) instead of the source's, asked through `Intl.PluralRules` ([translating](../packages/ai/llms/translating.md)).
- `kay i18n translate` translates a long entry body in parts instead of failing on the reply cap ([translating](../packages/ai/llms/translating.md)).
- `untranslated(schema)` from `kay/content` keeps a field out of `kay i18n translate`, whose dry run now lists the field paths of each entry ([content CMS](content-cms.md), [translating](../packages/ai/llms/translating.md)).
- kayjs-ai: `kay i18n translate` translates the `title`, `alt`, `aria-label` and `placeholder` of a tag and still holds its other attributes ([translating](../packages/ai/llms/translating.md)).
- `kay doctor` tries the port on `HOST` or else `localhost`, passes `PORT=0` as the system's pick, and reads a manifest again once when it is being written ([kay doctor](check-and-tools.md)).
- `kay doctor` tries the port on `HOST` or else on every IPv4 address and both loopback ones, passes `PORT=0` as the system's pick, and reads a manifest again once when it is being written ([kay doctor](check-and-tools.md)). A dev tool Network tab lists the page a swap took from a prefetch under the page it brings.
- A production build keeps the runtime split per island for a file that also imports `kay` as a namespace or default beside import text in a template literal or a comment, which it used to rewrite.
- kayjs-cms: in the on-page editor, the issues of a refused save stay shown when a draft render was pending, until the next edit ([kayjs-cms](../packages/cms/llms.txt)).
- An executable from `kay build --compile` maps an island's report and the stacks in its logs to `.kay` lines, with its maps embedded compressed, and a slow `onError` holds a queue worker for 10 seconds at most ([Build and start](build-and-start.md), [Error reporting](routing.md#error-reporting)).
- A warm build with `--compile` no longer compiles every `.kay` file again for its embedded maps, and the stacks of a static component rendered inside an island map to `.kay` lines in an executable ([Build and start](build-and-start.md)).
- An island passed an action without typing a prop with `Action` fails the render naming the fix, in production as in dev, instead of failing in the browser ([actions to islands](actions.md#pass-an-action-to-an-island)).
- A static component promoted to an island and passed an action works in the browser when it types a prop with `Action`, and fails the render naming the fix when it does not ([actions to islands](actions.md#pass-an-action-to-an-island)).
- `onError` gets the errors of `schedule`, `background` and queue jobs and `onStop` hooks, with no request, and an island's stack is mapped to `.kay` lines in production ([Error reporting](routing.md#error-reporting), [Error fallbacks](islands.md#error-fallbacks)).
- kayjs-cms: `cms({ collections })` arranges a form (field order, rows of columns, hidden fields) and a list (columns, row actions), and the screens' parts, `createEntryForm`, `entryScreen` and `listScreen` are exported to build an entry screen of your own ([screens](../packages/cms/llms/screens.md)).
- A page of many rules, Markdown pages included, links a copy of the stylesheet cut to the classes it names instead of every component's rules, loaded before a page swap paints ([styles](styles-and-assets.md#link-or-inline-the-stylesheets)).
- kayjs-ai's `Chat` announces each tool call's start and end to screen readers through its polite status line, and a Stop before the first word returns the message to the field ([Chat island](../packages/ai/llms/chat.md)).
- kayjs-ai's `Chat` names each table of a reply as a `group`, numbered when a reply has several, and escapes `tableLabel` ([Chat island](../packages/ai/llms/chat.md)).
- A tab opened before a deploy reloads itself, the scroll kept and what was typed left alone, on the next island it fails to load; production answers carry `x-kay-build` ([a deploy under open tabs](production.md#a-deploy-under-open-tabs)).
- kayjs-cms: a list of `imageField()` or `fileField()` takes several files dropped or picked at once, one item per file ([kayjs-cms](../packages/cms/llms.txt)).
- `unreachable-tooltip` no longer takes an `aria-label` on a role-less `span` or `div` as a fix, and leaves an expression `tabindex` or an element whose only text is its tooltip alone ([checks](checks.md)); kayjs-ui's TooltipHost describes the element it shows for with `aria-describedby`.
- `kay doctor` and an MCP `doctor` tool check Bun, kay and library versions, the config, the environment, the port and `.kay` in one report, with a fix beside each failure ([tools](check-and-tools.md)).
- The dev tool's Not found tab lists the paths production found nothing at, and turns one into a redirect with a click ([dev server](dev-server.md)).
- kayjs-cms lists those paths at `<prefix>/not-found`, with where visitors came from and a redirect line to copy ([Redirects](routing-endpoints-and-base.md#redirects)).
- The dev tool's filters update a group's count, Head's hreflang alternates have a copy button, and a copy's outcome is announced to a screen reader ([dev server](dev-server.md)).
- `cached(key, ttl, load, { live: true })` has every open page that read the key show it afresh when `invalidate` drops it, with no socket or polling ([live data](api-from-islands.md#following-cached-values)).
- `kay build` keeps the chunks of the last 3 builds beside the new one, so a tab opened before a deploy still finds them ([a deploy under open tabs](production.md#a-deploy-under-open-tabs)).
- An island's markup names its chunk (`data-chunk`), so a page no longer loads a loader for every island of the app: the docs' 128 islands weigh 2 KB gzip less on every page ([Build and start](build-and-start.md)). Island markup now carries `data-chunk`, so a test matching a `<slot>` exactly changes, and markup from `renderToString` has none and hydrates nothing.
- A page no longer loads a runtime module only other pages' islands use: the action runtime or the image variants stay with the islands importing them, and the docs' entry drops from 21.0 to 15.4 KB gzip ([Build and start](build-and-start.md)).
