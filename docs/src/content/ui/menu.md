## Entries

`items` lists the entries: an object with a `label`, an `onSelect`, an optional `icon` and `danger` for a destructive one, or `'separator'` to draw a rule between groups. `icon` sets the trigger's icon and `label` names it. The arrows, Home and End move between entries, and `onSelect` runs once the menu has closed and focus is back on the trigger.
