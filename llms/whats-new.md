# What's new

What each release of kay and its libraries adds, newest first, each feature with where it is documented. kay and its libraries share one version, so one section covers them all; what a release breaks is in [Upgrading](upgrading.md).

## Unreleased

- `kay lint` reads a signal a component imports from another module, and an icon of an installed `~icons/` set, as `kay check` does, where under Node it read the signal as a plain value and the icon as a component, so a template showing an imported signal lints as it type-checks: [Lint with ESLint](checks.md#lint-the-script-fences-and-template-expressions-with-eslint).
- `kay lint` lints a component or page with a `--- style` fence, which failed with `Bun is not defined` as ESLint runs under Node, so scoped styles no longer have to move out of components to lint clean: [Lint with ESLint](checks.md#lint-the-script-fences-and-template-expressions-with-eslint).
- `kay build` and `kay dev` build an app in a workspace on Bun's isolated linker, its default: the Tailwind plugin skips every file under `node_modules/.bun/`, so kay hands it a library's stylesheet kept there, such as kayjs-ui's shell, by the link the app reaches the package through, and `linker = "hoisted"` in `bunfig.toml` is no longer needed: [Component libraries](component-libraries.md).
- `kay build` and `kay dev` build an app in a workspace on Bun's isolated linker, its default: the Tailwind plugin skips every file under `node_modules/.bun/`, so kay hands it a stylesheet kept there, such as kayjs-ui's shell, by the link the app reaches its package through, and `linker = "hoisted"` in `bunfig.toml` is no longer needed: [Component libraries](component-libraries.md).
- With `i18n`, only the islands writing a link or reading `kay/i18n` load the code putting their links in the page's locale, so a page whose islands do neither ships about 2 KB gzip less: [Helpers](locales.md#helpers).
- kayjs-cms: a collection's list walks the git history for its Last modified and Author columns once per commit rather than on every view, and waits a second at most for it unless sorted by them, so a slow git no longer holds the page: [Screens](../packages/cms/llms/screens.md).
- kayjs-auth: a passkey added or signed in with in a frame of another site, its client data saying `crossOrigin` or naming a `topOrigin`, is refused, as kay's `frame-ancestors 'self'` already keeps other sites from framing the sign-in pages: [Passkey rules](../packages/auth/llms/oauth-passkeys-two-factor.md#passkey-rules).
- kayjs-auth: a passkey ceremony run in a frame of another origin, its client data saying `crossOrigin` or naming a `topOrigin`, is refused, as kay's `frame-ancestors 'self'` already keeps other origins from framing the sign-in pages: [Passkey rules](../packages/auth/llms/oauth-passkeys-two-factor.md#passkey-rules).
- kayjs-ui: `MapView` markers with a label or a popup are one tab stop the arrows walk, Enter opening the popup, the tiles darken while the map's scheme is dark (`darkTiles` swaps in a dark set, `--map-tiles-dark` sets the filter), and a change to `lines` or `markers` keeps the view once the visitor moved it: [MapView](../packages/ui/llms/charts-drag-and-media.md#mapview).
- `memoryJobs()` lists failed jobs oldest first, as `sqliteJobs` and `pgJobs` do, so a queue's `failed()` reads the same under `bun test` as in production: [Queues](queues.md#reference).
- An island hydrating over Markdown the server drew no longer fetches marked for `markdownHtml`: it loads once the text changes, so a page whose Markdown stays as written saves its 15 KB gzip: [Render Markdown a user writes](content.md#render-markdown-a-user-writes).
- `compressionDictionary: false` in kay.config.ts builds no compression dictionary, so no page names one and `kay build` writes no `.dcz` copy, and a rebuild keeps each page's `.dcz` copy in `.kay/cache` by the page and the dictionary, compressing again only the pages that changed: [Compression](proxy-and-security.md#compression).
- kayjs-ui: `Segmented(label="Grid" showLabel)` and `ChipGroup(showLabel)` write their label above the group in a Slider's label type and name the group by it, so an app writes no label of its own over one: [tables](../packages/ui/llms/tables-navigation-and-layout.md).
- kayjs-ai: `await reply.steps` lists the model requests a reply made, each `{ ms, firstTokenMs, usage, finish, calls }`, and a finished `ToolCall` has `ms`, so a slow tool loop shows whether the model or a tool took the time: [Asking](../packages/ai/llms/asking.md).
- kayjs-ai: under `bun test` an `ask` given its own `provider` is answered by the fake as one without is, `aiTest().last()` telling the `provider` and `model` it was for, so a job sent to another model is tested with no workaround; `KAYJS_AI_REAL_PROVIDERS=1` sends it to the provider instead: [The fake](../packages/ai/llms/testing-and-errors.md#the-fake).
- kayjs-ai: `aiTest().reply(script, asked => boolean)` (and `fail`) scripts the reply of the ask it accepts, by its `system`, `schema` or `messages`, so a test of an action asking in several passes no longer queues a placeholder for each pass before the one it means, and `aiTest().clear()` drops the scripts not read: [The fake](../packages/ai/llms/testing-and-errors.md#the-fake).
- kayjs-ui: `RowsField` is the repeatable rows field, a labelled box per column with Add and Remove, so a list of headers or addresses no longer needs a hand-rolled `for`, add button and row patch helper; it works in a signal editor (`onChange`), in a form posting to an action and inside a `SaveForm`: [RowsField](../packages/ui/llms/forms.md#rowsfield).
- kayjs-ui: a Table over a `list` sends its search box text to the list's `load` as `filter.text` and starts over from offset 0, and its `fields` (text boxes or selects) join it, kept in the URL under their `key`, so a server-side filter needs no GET form of its own; `list.filterBy` and `list.restart` do the same from code: [Infinite lists](../packages/ui/llms/infinite-list.md).
- kayjs-ui: `infiniteList(first, { action, input, failure })` pages through an action, doing the empty guard, `refresh: false` and the toast, and `pageFields` and `pageOf` give the action its `offset` and `limit` and cut a held list to a page, so a list repeats neither its loader nor its paging schema: [Infinite lists](../packages/ui/llms/infinite-list.md).
- kayjs-ui: `infiniteList` has `patch(id, change)`, which updates one loaded row by its `key` from an action's answer, so a toggle on a row needs no signal of changes merged over `rows()`: [Infinite lists](../packages/ui/llms/infinite-list.md).
- `kay check` reports `server-only-in-island` once per island reaching a module that reads `process` or `Bun`, finds the read in a component with a `--- server` fence that is an island and in a `.ts` module with an angle-bracket cast, and skips following imports in a project with no island: [Browser-only code](browser-only.md).
- `mediaQuery('(...)')` and `reducedMotion()` from `kay` are values following a media query or `prefers-reduced-motion` while an island lives, with the server rendering a stated fallback, and kayjs-ui's carousel, map and split layout use them: [Follow a media query](islands.md#follow-a-media-query).
- `timeZone` in kay.config.ts is the zone `formatDate`, a message's date and `RelativeTime`'s tooltip write in, on the server and in islands alike, and `kay/i18n` has `formatBytes` and `formatDuration` in the page's locale, so an app keeps no `format.ts` of its own: [Locales](locales.md#helpers).
- kayjs-ui: `DateTimeInput(name="startsAt" min={now})` shows a date and time on the visitor's clock and posts the instant with the visitor's offset, which `s.Date()` reads right, so an app posts no `getTimezoneOffset()` fields: [forms](../packages/ui/llms/forms.md).
- An `s.Files` field without `maxItems` raises its action's body limit by ten files of its `maxSize`, not one, so a post of several files within their size is no longer refused with a 413: [Files posted to an action](files.md#files-posted-to-an-action).
- kayjs-ui: `Stat` draws its change after its label for a screen reader, an empty `StatusStrip` cell is a hairline along the bottom apart from a `muted` one, and a `DescriptionList` item with neither a `value` nor a block shows a dash: [basics](../packages/ui/llms/basics.md#stat-meter-progress-skeleton-barlist-sitefavicon-copybutton-rating).
- kayjs-ui: `attempt(run, { failure, onRefused(data) })` hands a refusal (an action's `ctx.fail` data or a route's JSON answer) to the app and toasts nothing, so showing it in a Dialog or a Notice needs no `try`/`catch` and `action.refused`: [Toasts](../packages/ui/llms/basics.md).
- kayjs-ui: `SaveForm` takes `cancelHref` for a Cancel link, `confirm` for a question asked before saving and `saveDisabled` to keep Save off with its reason as a tooltip, so an editor with a Cancel, a confirm step or an invalid draft keeps no save bar of its own: [Forms](../packages/ui/llms/forms-and-steps.md).
- kayjs-ui: a long word with no space to break at (an image reference, a digest, a path) breaks inside `PageHeader`, `Card`, `Notice` and `Table` instead of widening a phone's page, so an app drops its own `wrap-anywhere` on their parts: [PageHeader](../packages/ui/llms/page-layout-palette-and-trees.md#pageheader-pagesection-collapsiblesection-accordion-widget-cardrow-sidepanel-toolbar-splitlayout).
- `site.logs` in `kay/test` lists the entries the server logged during the test, a `logFrom` line of the app's included, so a log line is asserted with no spy on `console`: [Read the log](testing.md#read-the-log).
- A component mounted by `mountComponent` has `setProps({ tiles })`, giving it new values for some of its props as a parent would, so a component following a prop is tested without a wrapper island: [Mounting a component](testing.md#mounting-a-component).
- `signal-set-call` also reports `consent.set('yes')` on the `consent` signal of `kay/analytics`, and `--fix` assigns it: [Signals](components.md#signals).
- `kay check` on a block written without the parameters its component calls it with (`@value` for a `Snippet<[item: Item]>`) names them in its help, as `@value(item)`, where it only said TS2322 on `Element`: [Slots and snippets](templates-elements-slots-snippets.md).
- A `withQuery` link in an island follows the address: it is built again after each `navigate({ query })`, page swap, Back and `persisted` query write, instead of keeping the query of the render: [Navigating from code](navigation-from-code.md#navigating-from-code).

## 1.80.0

- `formatNumber`, `formatDate`, `formatRelativeTime`, `formatList` and `direction` from `kay/i18n` work outside a request, in the site's default locale, so a job, an alert or a push formats like its pages, and each takes a `locale` option (`formatDate(date, { locale: user.locale })`) that wins over the page's, in the browser too: [Format a number, a date or a list](locales.md#format-a-number-a-date-or-a-list).
- `promoted-island` no longer reports a static component for a value read from an object of strings or numbers another module exports as a literal (`LABEL[kind]`), by name, in `export { LABEL }`, by default, re-exported or imported from a `.json` file, as it is data and not a function: [Islands](islands.md#islands).
- `fakeService(routes)` from `kay/test` stands in for an outside HTTP service: a real loopback server whose `url` feeds `overrideEnv`, that records its `requests`, answers errors with `fail(status)` and holds requests with `stall()`, and stops with the test file, so no test hand-rolls a `Bun.serve` fake or a `fetch` spy: [Testing](testing.md#test-an-app-calling-an-outside-api).
- `testSite({ proxyKey })` checks the `proxy.key` header for that site alone and sends the key with every request, so a test of an app behind a proxy writes no `KAY_PROXY_KEY`: [Testing](testing.md).
- kayjs-ui has a `RelativeTime(date)`: a `time` worded relative to now in the page's locale (`3 hours ago`), ticking in the browser and hydrating the text the server drew, with the full date as a tooltip reachable by keyboard: [basics](../packages/ui/llms/basics.md).
- kayjs-ui has a `Tooltip(text="...")` wrapping text in a tab stop that `TooltipHost` shows the tooltip of, so no hand `tabindex="0"` is needed, and a `Button` that is `disabled` with a `data-tooltip` renders `aria-disabled` instead, staying focusable to read its reason while ignoring its press. `kay check --fix` rewrites a hand-written `span(data-tooltip tabindex="0")` to `Tooltip` (`hand-tooltip`): [basics](../packages/ui/llms/basics.md#popover-hovercard-tooltiphost).
- `sanitizeHtml(markup, { base })` resolves the relative URLs of markup fetched from elsewhere against its address, and the links it keeps that leave your site open in a new tab, like a template's: [Templates](templates-elements-slots-snippets.md).
- `mcp: { key }` requires a bearer key on the MCP endpoint and so on its tool calls, from `KAY_MCP_KEY` or `KAY_MCP_KEY_FILE` (`key: true`), a string, or `{ file }` made on first use, compared in constant time; with `proxy.key` the endpoint needs no `proxy.open` entry and no app guard, `kay env` lists the variables, and `testSite({ mcpKey })` sends the key from `site.mcp`: [API routes](api-routes.md#mcp).
- A module an island imports may build schemas with `s` as it loads: in the browser `s` builds an inert stand-in with no validator, so a type and its schema live in one module shared with the server, and `server-only-in-island` no longer refuses `s`, only `process` and `Bun` reads: [Schemas](schemas.md#schemas).
- kayjs-ai: `ask` outside a request takes `tool({ name, description, input, run })` functions as `tools`, run with the app's own rights and never held for approval, so a scheduled job's model can call things: [Function tools](../packages/ai/llms/tools.md#function-tools).
- kayjs-ui has an `AudioPlayer`: chapters on a timeline and in a list, a timed transcript following the playback, lock screen controls skipping between chapters, an `@actions` slot per chapter and a readable position ([Charts, drag and drop and media](../packages/ui/llms/charts-drag-and-media.md)).
- kayjs-ai `reasoning` now works on `anthropic()`, as adaptive thinking at that effort (`'none'` asks the lowest effort with thinking off), what the model thinks streams as `reasoning` in `reply.progress()` for Anthropic and OpenAI-compatible servers without touching `await reply`, tool loops send Anthropic's thinking blocks back, and `Chat` folds it above the reply, `reasoning={false}` hiding it: [asking](../packages/ai/llms/asking.md#ask-options), [chat](../packages/ai/llms/chat.md#props).
- kayjs-ai `ask(..., { body })`, and `openai({ body })` and `anthropic({ body })` for every ask of a provider, add fields kayjs-ai does not model (`top_p`, `seed`, `stop`, `top_k`, OpenRouter's `provider`) to the request body, so a new provider parameter needs no release: [asking](../packages/ai/llms/asking.md#fields-kayjs-ai-does-not-model).
- kayjs-ai: a user message holds `attachments`, images and PDFs from a `File`, `Blob`, bytes or a stored file, sent as each provider expects and readable into a `schema`, with `maxAttachmentBytes`, a price in characters against `maxInputChars` and an `unsupported` error; `Chat` takes `attach` with the upload's type and size checks; the fake records them in `asked`: [Images and PDFs](../packages/ai/llms/attachments.md), [Chat](../packages/ai/llms/chat.md#attaching-files).
- kayjs-ai: `Chat(regenerate)` asks again for the last reply and `Chat(editable)` resends an edited message with every later turn gone, and an action reads `replaces()` to drop the stored turns they replace; kayjs-ui has `refresh` and `edit` icon slots: [chat](../packages/ai/llms/chat.md#regenerating-and-editing).
- kayjs-ai: `Chat(fill)` takes the height of its container, the log (or the greeting) taking the space and the form staying at the bottom, for a chat that is a page's main content: [chat](../packages/ai/llms/chat.md#props).
- `kay check` reports `signal-set-call`, a signal written `count.set(value)` where assigning it, `count = value`, does the same, and `--fix` assigns it: [Signals](components.md#signals).

## 1.79.0

- The `kay` preset of `@kaynooo/eslint` (7.1.4) turns `ts/await-thenable` off in an app's test files, so `await expect(...).rejects...` lints clean with no override: [Lint with ESLint](checks.md#lint-the-script-fences-and-template-expressions-with-eslint).
- `kay check` reports `server-only-in-island` for an island, or a module it imports, that builds schemas with `s` or reads `process` or `Bun` as it loads, at the island's import line, where the build used to be the first to refuse it: [Server globals in the browser](browser-only.md#server-globals-in-the-browser).
- `kay docs <words>` prints the section of kay's or an installed library's llms files that words or a name match, with the labels of the next matches and, for a component, its props read from its installed source, `kay mcp` has it as its `docs` tool and `kay explain` of a name that is no lint points at it, so an agent finds a topic in one call: [Find a topic in the docs](editor-and-agent-commands.md#find-a-topic-in-the-docs).
- kay's manifest link carries `crossorigin="use-credentials"`, so an app behind a cookie login proxy loads its manifest and installs: [Favicon and web manifest](sitemap-search-fonts.md#favicon-and-web-manifest).
- kayjs-ui has a `Timeline`, a vertical list of time-stamped entries with an optional icon or muted tone, each pickable through a bindable `selected` key ([Page layout](../packages/ui/llms/page-layout-palette-and-trees.md)).
- kayjs-ui's `MapView` draws polylines and markers over raster tiles with Leaflet, loaded only on pages using it, fitted to what it draws, with a `highlight` path brought into view, OpenStreetMap's tiles by default and the skin's colours: [kayjs-ui](../packages/ui/llms/charts-drag-and-media.md).
- kayjs-ai: a resume or stop of a reply the server kept gives back the attempt the action's `protect.rateLimit` counted, so reloading a page does not spend the limit; a `RateStore` takes an optional `refund(key, resetAt)` for it: [Asking](../packages/ai/llms/asking.md#a-reply-that-outlives-the-visitor), [Rate limits](rate-limits.md).
- kayjs-ai: `ask(messages, { outlive: true })` lets a reply finish on the server, tool loop and readers included, after the visitor reloaded or left, and a `Chat` with `remember` shows the finished turn after the reload or picks the stream back up, with no app code; an action call takes `{ headers }`: [Asking](../packages/ai/llms/asking.md#a-reply-that-outlives-the-visitor), [Chat](../packages/ai/llms/chat.md#a-reply-that-outlives-the-page).

Releases before 1.79 are in [What's new, older releases](whats-new-archive.md).
