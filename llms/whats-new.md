# What's new

What each release of kay and its libraries adds, newest first, each feature with where it is documented. kay and its libraries share one version, so one section covers them all; what a release breaks is in [Upgrading](upgrading.md).

## Unreleased

- An `s.Files` field without `maxItems` raises its action's body limit by ten files of its `maxSize`, not one, so a post of several files within their size is no longer refused with a 413: [Files posted to an action](files.md#files-posted-to-an-action).
- kayjs-ui: a long word with no space to break at (an image reference, a digest, a path) breaks inside `PageHeader`, `Card`, `Notice` and `Table` instead of widening a phone's page, so an app drops its own `wrap-anywhere` on their parts: [PageHeader](../packages/ui/llms/page-layout-palette-and-trees.md#pageheader-pagesection-collapsiblesection-accordion-widget-cardrow-sidepanel-toolbar-splitlayout).
- A component mounted by `mountComponent` has `type(selector, text)`, `click(selector)` and `press(key)` firing the events a browser would, then settling, so a test no longer dispatches input events by hand: [Mounting a component](testing.md#mounting-a-component).
- A browser test's `page.waitUntil(fn, { what })` names the wait in its timeout error, and a timed-out `waitFor` or `waitUntil` carries the stack of the test's own call: [Browser tests](testing-browser.md).
- kayjs-auth: `authTest(site).oauth.stub(provider, { id, email })` makes an OAuth provider answer with a stated account, or with `{ error }` for a refused consent, a rejected code or a provider down, and `oauth.signIn(provider)` signs the test site in through it, with no `fetch` spy: [Testing](../packages/auth/llms/hardening-and-testing.md).
- kayjs-auth: `authTest(site).enrollTotp(userId)` (and `auth.enrollTotp` on a module's auth) turns two-factor on for a member in a test and answers its `secret`, a `code()` and the recovery codes, so a test no longer writes `totpEnabledAt`: [Testing](../packages/auth/llms/hardening-and-testing.md).
- kayjs-auth: `forwardAuth` gives the session cookie the domain the visited host is on, with no `domain` on `session()` (the cookie is named `kay_session` rather than `__Host-kay_session` then, so signed-in users of such an app sign in once more), and `auth({ cookie })` names the session cookie: [Guarding other sites](../packages/auth/llms/oauth-server-and-tokens.md).
- kayjs-ai: a `Chat` without `attach` no longer ships the `FileDrop` component in its island, and with `attach` it posts the files of the messages before the last again only up to 8 MB, the newest first: [Chat](../packages/ai/llms/chat.md#attaching-files).
- `withQuery({ page: 2, sort: null })` from `kay` gives the current page's path with those query params set or dropped, in a server fence or an island, for a link to the page itself: [Navigating from code](navigation-from-code.md#navigating-from-code).
- A page's `query` field with `lenient: true` reads a value its schema refuses as its default, or leaves it out, instead of answering 400, and stays typed by the real schema: [Routing](routing.md#reference).
- A string `defineEnv` field also reads `<NAME>_FILE`, the path of a file holding its value, trimmed and read once at boot, as a compose secret hands it; both set, or a file missing, unreadable or empty, stops the boot naming them, and `kay env` and `kay check` count the file form: [Environment](environment.md#environment).
- `basicAuth({ user, password, realm })` from `kay/server` is a `_guard.ts` for HTTP Basic: constant-time, 401 with `WWW-Authenticate`, and every request refused while the credentials are unset: [Guards](server.md#basic-auth).
- `s.File` and `s.Files` take `minSize` and `maxSize` as `'2mb'`, as an action's `maxSize` does, and an action with no `maxSize` of its own takes as many bytes as its sized file fields add up to, so a limit is written once: [Files posted to an action](files.md#files-posted-to-an-action).
- `sanitizeHtml` adds `noopener` to the `rel` of a link whose kept `target` is not `_self`, so a `target="_blank"` the options let through gives the page no `window.opener`: [Templates](templates-elements-slots-snippets.md).
- `schedule` and `background` take `enabled: false` to add nothing, and `KAY_LOCK_SCHEDULES=false` stops a one-process production server locking every schedule: [Background jobs](production.md#background-jobs).
- `waitUntil(condition, { timeout, what })` from `kay/test` polls a sync or async condition in a server test until it is truthy, and fails naming what it waited for and the last value seen: [Testing requests, jobs and sockets](testing-requests-jobs-sockets.md).
- kayjs-ai: a `Chat` renders each turn once, an `initial` turn with sources hydrates formatted without a flash (a citation only inside code or a fence lists nothing), `[01]` and five-digit citations stay text, a reply link written `/\host` counts as another site under `links="here"`, and the sources list is named for screen readers; `isHeldMarkdown(html)` from `kay/markdown` tells the stand-in an island writes while its renderer loads: [Chat sources](../packages/ai/llms/chat-sources.md).
- kayjs-ai: `ChatLauncher` takes `Chat`'s `regenerateIcon` and `editIcon` blocks, and a static component spreading props that hold markup (`Snippet`) onto an island no longer hits TS2589 in `kay check`: [Chat](../packages/ai/llms/chat.md).
- kayjs-ai: an open `Chat` edit survives a message sent from outside and an Allow or Deny, Escape on its Save or Cancel button cancels it without closing a `ChatLauncher` panel, Cancel and Escape return the focus to the message's edit button (now named `Edit the message: <start>`), a Save with nothing to send says so (`editEmptyLabel`), Enter in the field while a reply is under way says why nothing happens (`editBusyLabel`), and the button name never splits an emoji: [Chat](../packages/ai/llms/chat.md).
- kayjs-ui: `Stat(href)` makes the whole stat a link and `Stat(delta)` shows the change from the previous period beside the figure with an arrow, from the new `trendUp`, `trendDown` and `trendFlat` icon slots: [basics](../packages/ui/llms/basics.md#stat-meter-progress-skeleton-barlist-sitefavicon-copybutton-rating).
- kayjs-ui has a `Sparkline(values, label)` of axis-free bars with a tone per bar and a pointer note per bar, and a `StatusStrip(cells, label)` of coloured cells read as one sentence instead of a tooltip per cell: [charts](../packages/ui/llms/charts-drag-and-media.md#linechart-barchart-scatterchart-contributiongraph-sparkline-statusstrip).
- kayjs-ui: a `BarList` row takes `href`, drawing its label as a real link (middle-click and a new tab work) while the bar stays under it: [basics](../packages/ui/llms/basics.md).
- kayjs-ui has a `DescriptionList(items)`: a `dl` of labels and values that start at one column, an `@value(item)` block drawing the rich ones, each label above its value in a box narrower than 24rem: [page layout](../packages/ui/llms/page-layout-palette-and-trees.md#descriptionlist).
- kayjs-ui: a narrow `Table`'s stacked cards draw their own top line, so they stay apart when the app drops the `row` part's border: [tables](../packages/ui/llms/tables-navigation-and-layout.md).
- kayjs-ui: a `TimeInput` with `required` never calls `onChange` with `''`, and goes back to the last time once it is left empty: [forms](../packages/ui/llms/forms.md).
- kayjs-ui: the `AudioPlayer` cue arrows follow the reading direction, its next button keeps the focus when the last chapter disables it, and the transcript's wheel and touch listeners are passive: [media](../packages/ui/llms/charts-drag-and-media.md).
- kayjs-ui: a disabled `IconButton` or `BareIconButton` renders `aria-disabled` and stays a tab stop with its label as the tooltip, as a disabled `Button` with a tooltip does, and the `popovertarget` or `command` of a locked button opens nothing: [Button](../packages/ui/llms/basics.md#icon-button-iconbutton).
- `cached(key, ttl, load, { stale: false })` waits for a fresh load past its ttl instead of giving the stale value, concurrent callers sharing it, and `{ fallback }` answers a value when the first load throws, logging the error and trying again a minute later at most; `cache()` takes both: [Caching](rendering.md#caching).
- `s.UnionEnum(values)` no longer defaults to its first value: an optional enum field left out reads `undefined`, and a required one is refused instead of filled in, in an action, a page's `query`, `defineEnv` and content; pass `{ default }` for one: [Actions](actions.md).
- A form post's outcome (`succeeded()`) stays in its cookie until the page the post goes back to renders it: a prefetch, another tab or any request for another page racing the swap no longer takes it: [Privacy](privacy.md).
- kayjs-ui has a `kui-prose` class for running text you did not template, such as `markdownHtml`, `renderMarkdown` or `sanitizeHtml` output set through `innerHTML`: headings, lists, links, quotes, code, tables and images from the theme tokens, a wide table or code block scrolling inside it. The MarkdownEditor preview and kayjs-ai's Chat replies use it: [forms](../packages/ui/llms/forms.md).
- kayjs-ai: `ask(messages, { sources })` and `Chat`: a reply cites documents as `[n]`, the chat links each outside code to its source and lists the cited ones under the turn, in a new tab for an outside link, and the sources survive `remember` and `initial`, so a research app rewrites no markdown: [Chat sources](../packages/ai/llms/chat-sources.md).
- kayjs-ai: `reply.resumed` is true on the reply of a Chat's resume or stop of an `outlive` reply, and `resuming()` tells it before `ask`, so an action reads the reply on the server once with `if (!answer.resumed) void speak(answer)`: [asking](../packages/ai/llms/asking.md#a-reply-that-outlives-the-visitor).
- kayjs-ui has an `external` icon slot, drawn by the `AudioPlayer` chapter links, that an app replaces through its settings like the others: [setup](../packages/ui/llms/setup.md#settings).

## 1.80.0

- `formatNumber`, `formatDate`, `formatRelativeTime`, `formatList` and `direction` from `kay/i18n` work outside a request, in the site's default locale, so a job, an alert or a push formats like its pages, and each takes a `locale` option (`formatDate(date, { locale: user.locale })`) that wins over the page's, in the browser too: [Format a number, a date or a list](locales.md#format-a-number-a-date-or-a-list).
- `promoted-island` no longer reports a static component for a value read from an object of strings or numbers another module exports as a literal (`LABEL[kind]`), by name, in `export { LABEL }`, by default, re-exported or imported from a `.json` file, as it is data and not a function: [Islands](islands.md#islands).
- `fakeService(routes)` from `kay/test` stands in for an outside HTTP service: a real loopback server whose `url` feeds `overrideEnv`, that records its `requests`, answers errors with `fail(status)` and holds requests with `stall()`, and stops with the test file, so no test hand-rolls a `Bun.serve` fake or a `fetch` spy: [Testing](testing.md#test-an-app-calling-an-outside-api).
- `testSite({ proxyKey })` checks the `proxy.key` header for that site alone and sends the key with every request, so a test of an app behind a proxy writes no `KAY_PROXY_KEY`: [Testing](testing.md).
- kayjs-ui has a `RelativeTime(date)`: a `time` worded relative to now in the page's locale (`3 hours ago`), ticking in the browser and hydrating the text the server drew, with the full date as a tooltip reachable by keyboard: [basics](../packages/ui/llms/basics.md).
- kayjs-ui has a `Tooltip(text="...")` wrapping text in a tab stop that `TooltipHost` shows the tooltip of, so no hand `tabindex="0"` is needed, and a `Button` that is `disabled` with a `data-tooltip` renders `aria-disabled` instead, staying focusable to read its reason while ignoring its press. `kay check --fix` rewrites a hand-written `span(data-tooltip tabindex="0")` to `Tooltip` (`hand-tooltip`): [basics](../packages/ui/llms/basics.md#popover-hovercard-tooltiphost).
- `sanitizeHtml(markup, { base })` resolves the relative URLs of markup fetched from elsewhere against its address, and the links it keeps that leave your site open in a new tab, like a template's: [Templates](templates-elements-slots-snippets.md).
- `mcp: { key }` requires a bearer key on the MCP endpoint and so on its tool calls, from `KAY_MCP_KEY` or `KAY_MCP_KEY_FILE` (`key: true`), a string, or `{ file }` made on first use, compared in constant time; with `proxy.key` the endpoint needs no `proxy.open` entry and no app guard, `kay env` lists the variables, and `testSite({ mcpKey })` sends the key from `site.mcp`: [API routes](api-routes.md#mcp).
- A module an island imports may build schemas with `s` as it loads: in the browser `s` builds an inert stand-in with no validator, so a type and its schema live in one module shared with the server, and `server-only-in-island` no longer refuses `s`, only `process` and `Bun` reads: [Schemas](schemas.md#schemas).
- kayjs-ai: `ask` outside a request takes `tool({ name, description, input, run })` functions as `tools`, run with the app's own rights and never held for approval, so a scheduled job's model can call things: [Function tools](../packages/ai/llms/tools.md#function-tools).
- kayjs-ui has an `AudioPlayer`: chapters on a timeline and in a list, a timed transcript following the playback, lock screen controls skipping between chapters, an `@actions` slot per chapter and a readable position ([Charts, drag and drop and media](../packages/ui/llms/charts-drag-and-media.md)).
- kayjs-ai `reasoning` now works on `anthropic()`, as adaptive thinking at that effort (`'none'` asks the lowest effort with thinking off), what the model thinks streams as `reasoning` in `reply.progress()` for Anthropic and OpenAI-compatible servers without touching `await reply`, tool loops send Anthropic's thinking blocks back, and `Chat` folds it above the reply, `reasoning={false}` hiding it: [asking](../packages/ai/llms/asking.md#ask-options), [chat](../packages/ai/llms/chat.md#props).
- kayjs-ai `ask(..., { body })`, and `openai({ body })` and `anthropic({ body })` for every ask of a provider, add fields kayjs-ai does not model (`top_p`, `seed`, `stop`, `top_k`, OpenRouter's `provider`) to the request body, so a new provider parameter needs no release: [asking](../packages/ai/llms/asking.md#fields-kayjs-ai-does-not-model).
- kayjs-ai: a user message holds `attachments`, images and PDFs from a `File`, `Blob`, bytes or a stored file, sent as each provider expects and readable into a `schema`, with `maxAttachmentBytes`, a price in characters against `maxInputChars` and an `unsupported` error; `Chat` takes `attach` with the upload's type and size checks; the fake records them in `asked`: [Images and PDFs](../packages/ai/llms/attachments.md), [Chat](../packages/ai/llms/chat.md#attaching-files).
- kayjs-ai: `Chat(regenerate)` asks again for the last reply and `Chat(editable)` resends an edited message with every later turn gone, and an action reads `replaces()` to drop the stored turns they replace; kayjs-ui has `refresh` and `edit` icon slots: [chat](../packages/ai/llms/chat.md#regenerating-and-editing).
- kayjs-ai: `Chat(fill)` takes the height of its container, the log (or the greeting) taking the space and the form staying at the bottom, for a chat that is a page's main content: [chat](../packages/ai/llms/chat.md#props).
- `kay check` reports `signal-set-call`, a signal written `count.set(value)` where assigning it, `count = value`, does the same, and `--fix` assigns it: [Signals](components.md#signals).

## 1.79.0

- The `kay` preset of `@kaynooo/eslint` (7.1.4) turns `ts/await-thenable` off in an app's test files, so `await expect(...).rejects...` lints clean with no override: [Lint with ESLint](checks.md#lint-the-script-fences-and-template-expressions-with-eslint).
- `kay check` reports `server-only-in-island` for an island, or a module it imports, that builds schemas with `s` or reads `process` or `Bun` as it loads, at the island's import line, where the build used to be the first to refuse it: [Server globals in the browser](browser-only.md#server-globals-in-the-browser).
- `kay docs <words>` prints the section of kay's or an installed library's llms files that words or a name match, with the labels of the next matches and, for a component, its props read from its installed source, `kay mcp` has it as its `docs` tool and `kay explain` of a name that is no lint points at it, so an agent finds a topic in one call: [Find a topic in the docs](editor-and-agent-commands.md#find-a-topic-in-the-docs).
- kay's manifest link carries `crossorigin="use-credentials"`, so an app behind a cookie login proxy loads its manifest and installs: [Favicon and web manifest](sitemap-search-fonts.md#favicon-and-web-manifest).
- kayjs-ui has a `Timeline`, a vertical list of time-stamped entries with an optional icon or muted tone, each pickable through a bindable `selected` key ([Page layout](../packages/ui/llms/page-layout-palette-and-trees.md)).
- kayjs-ui's `MapView` draws polylines and markers over raster tiles with Leaflet, loaded only on pages using it, fitted to what it draws, with a `highlight` path brought into view, OpenStreetMap's tiles by default and the skin's colours: [kayjs-ui](../packages/ui/llms/charts-drag-and-media.md).
- kayjs-ai: a resume or stop of a reply the server kept gives back the attempt the action's `protect.rateLimit` counted, so reloading a page does not spend the limit; a `RateStore` takes an optional `refund(key, resetAt)` for it: [Asking](../packages/ai/llms/asking.md#a-reply-that-outlives-the-visitor), [Rate limits](rate-limits.md).
- kayjs-ai: `ask(messages, { outlive: true })` lets a reply finish on the server, tool loop and readers included, after the visitor reloaded or left, and a `Chat` with `remember` shows the finished turn after the reload or picks the stream back up, with no app code; an action call takes `{ headers }`: [Asking](../packages/ai/llms/asking.md#a-reply-that-outlives-the-visitor), [Chat](../packages/ai/llms/chat.md#a-reply-that-outlives-the-page).

Releases before 1.79 are in [What's new, older releases](whats-new-archive.md).
