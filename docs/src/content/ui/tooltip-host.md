<Demo name="tooltip-host/basic" />

Render one `TooltipHost` in the root layout, then add `data-tooltip` to any element. It shows on hover and on keyboard focus. `data-tooltip-placement` sets where it sits, as a CSS `position-area` (`top` by default).

<Callout type="note">

This page already renders the `TooltipHost`.
