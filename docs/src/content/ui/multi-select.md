## Search and forms

Past eight options, or with `search`, the panel opens on a search box filtering the options. `placeholder` is what the trigger reads while nothing is picked, and `selectedLabel(count)` words the count once several are. Screen readers hear the trigger as its label and that summary. `name` submits each picked value as a hidden field, so the control works inside a plain form.
