# Code lints

## Common tasks

- Set a lint's level, allow it on one line or apply its quick fix: [Lints and warnings](lints.md).

## Reference

- The `code` group reads scripts, templates, styles and project files for what does nothing, runs late or breaks a build.

| Lint | Default | Group | Reports |
| --- | --- | --- | --- |
| `unread-name` | deny | code | A prop, server value, import or declaration nothing reads (see [What `kay check` verifies](checks.md#what-kay-check-verifies)). |
| `incomplete-match` | warn | code | A `match` with no `else` over a finite union (literals, an enum, a boolean, `null`, `undefined`) whose `when` lines leave members out, naming them: it renders nothing for them. Found by the type check, so by `kay check` and the editor. A `match` with an `else`, over `string`, `number` or an object type, over `typeof` or `true`, or with a `when` value that is not a literal or an enum member, is not reported. |
| `css-import-without-text` | deny | code | A stylesheet imported for a value without `with { type: 'text' }`, whose value Bun and the compiled executable would give apart; in `.kay` fences and the project's own modules alike. |
| `brace-in-attribute` | warn | code | A quoted attribute of an HTML element holding `{name}`, `{user.name}` or `{count(1)}`: only text interpolates, so the braces ship as written. The quick fix writes `title={name}`, or a template literal for mixed text, and is safe for a name in scope; `\{` keeps a literal brace. A component's quoted prop is left alone. |
| `async-reply` | warn | code | An `async` function returning kayjs-ai's `ask()`, which awaits the reply so nothing streams; a local `const` holding the reply counts; the fix removes `async` where every returned value is the reply, a function awaiting first returns `ask(...).stream()`. |
| `unreturned-fail` | warn | code | A `ctx.fail(...)` statement (or a destructured `fail(...)`) in an action's handler that is not returned, which does nothing as `fail` returns the failure where `deny`, `notFound` and `redirect` throw; an expression-bodied arrow and a nested function are left alone, the fix prepends `return`. |
| `once-read-prop` | warn | code | A destructured prop read into a top-level `const` or `let` that a function or the template reads later, in a component that runs in the browser: the declaration runs once, so the value keeps the prop's first value after the parent changes it. A prop read as the test of an `if` or a ternary, an argument of a call or `new`, a write target, in a class, or inside `signal(...)`, `persisted(...)` or `posted...(...)`, `id ?? uid()`, a callback prop, a prop named `initial*` or `default*` are choices made once; otherwise compute the value where it is used or in a `memo`, or allow it with `// kay-allow once-read-prop: why the first value is meant`. |
| `literal-tag` | warn | code | Template text holding an HTML tag, `p Press <kbd>Ctrl</kbd>`: text is escaped, so readers see the tag as written. Text inside `code`, `pre`, `kbd` and `samp`, an entity such as `&lt;kbd&gt;` and a name that is no element, as in `Array<string>`, are left alone. The quick fix writes a pair around plain text, or a void element, as `#[kbd Ctrl]`. |
| `unkept-page` | warn | code | A page saying `keep: true` that `kay build` does not keep prerendered, as it reads the request or the clock, imports a package, holds module state or renders differently each time: reported by `kay build` at the file and line that decided it, never by `kay check`, and no `// kay-allow` comment reaches it. |
| `uncaught-await` | warn | code | An `await` block with no `catch` block and no `try` around it: once its value rejects, the pending block goes with nothing in its place and the error only reaches the log. |
| `removed-ui-token` | warn | code | A kayjs-ui theme token or utility under its old `kui-` name, such as `--color-kui-canvas` or `bg-kui-surface2`, which stopped working in 1.75: a utility builds nothing and a `var()` of it resolves to nothing. `kay check --fix` rewrites it to the app's own name where one stands for it, and the report says where to set the rest: a `--kui-border-*` knob and a `kui-` utility with no new form are reported without a fix. Names quoted in a comment are not reported |
| `unknown-tool-label` | warn | code | A key of a `toolLabels` object on `Chat` that names no tool of the project (an export in snake case, a `tool.name` or the name of a `tool()`), whose calls show the raw name. |
| `public-env-outside-src` | warn | code | An `s.Public(` in a `.ts` file outside `src/` (tests left out), such as `common/env.ts`: kay finds public fields only in the modules under `src`, so an island reads it as a plain string and the browser is not sent it. Declare the field in a `defineEnv` in a module under `src`. Reported by `kay check`, set with `lints` or allowed with `// kay-allow public-env-outside-src` |
| `browser-global-at-load` | deny | code | A module a page imports reading `window` or another browser-only name as it loads ([details](browser-only.md#browser-globals-on-the-server)). |
| `unmounted-jobs` | warn | code | A `src/jobs.ts` that no plugin under `src/plugins/` and no `src/server.ts` imports directly (not through a third module): the queues in it are mounted by nothing, so none runs. Define and mount queues in `src/plugins/jobs.ts`, the one home of jobs; a plugin re-exporting `src/jobs.ts` is accepted. |
| `unused-status-page` | warn | code | A status page (`_401.kay`, `_403.kay`, `_429.kay`, `_503.kay`) in a directory with no route: it answers for the routes of its directory and below, so no page renders it. Move it beside the pages it answers for, or delete it. |
| `endpoint-export` | warn | code | An endpoint file exporting a name that is no method, other than `page`: only `GET`, `HEAD`, `POST`, `PUT`, `PATCH`, `DELETE` and `OPTIONS`, in capitals, are called. A name differing from a method by its case is reported with the method. |
| `hidden-tool` | warn | code | With `mcp`, an API route whose `detail` sets `hide: true` and `tool`: a hidden route is no tool. |
| `trusted-folder` | warn | code | A folder collection with `trusted`, which only a loader's collection reads |
| `held-back-reference` | warn | code | A shown entry whose `reference()` names one its collection holds back (a draft, or outside its publication dates) |
| `old-bun-image` | deny | code | A root Dockerfile with `FROM oven/bun:<version>` older than the Bun kay needs (`engines.bun`), which fails the image build once `kay upgrade` moves kay up. `--fix` moves the tag to the Bun kay needs, not a digest pin; a tag that is no full version is left alone. Reported by `kay check`, and no `// kay-allow` comment reaches it. |
| `unused-selector` | warn | code | A `--- style` rule whose last compound no element of the template can have; a spread, `class` expression, `part` or class string in the code counts as a match. |
| `unreachable-selector` | deny | code | A `--- style` rule ending on `:root`, `html` or `body`, which carry no scope attribute; `:global(...)` is the fix, offered, never applied by `--fix`. |
| `untyped-socket` | warn | code | An API route `.ws()` with a `body` and no `response`, so an island's `socket()` receives its messages as `unknown`. Add `response: chats.response` when it sends through `rooms()`, or a `response` schema; routes read only by other clients can allow it. A route written with an object literal of options and no spread is read; reported by `kay check` at the `.ws`, and no `// kay-allow` comment reaches it. |
| `over-budget` | warn | code | A page loading more JavaScript or CSS, compressed, than `budget` in kay.config.ts allows, or a route whose heaviest prerendered page weighs more whole than `budget.weight` or has a worse EcoIndex grade than `budget.grade`: reported by `kay build` at the route's file with the modules weighing most in its scripts for `js` and `css`, never by `kay check`, and no `// kay-allow` comment reaches it. `kay build --deny-warnings` or `lints: { 'over-budget': 'deny' }` fails the build on it. |
