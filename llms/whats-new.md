# What's new

What each release of kay and its libraries adds, newest first, each feature with where it is documented. kay and its libraries share one version, so one section covers them all; what a release breaks is in [Upgrading](upgrading.md).

## Unreleased

- The editor completes the attributes and events of a plain element from `JSX.IntrinsicElements` (`onDblClick`, `inputmode`, `form`, `aria-*`, `transition:*`), the words of an enumerated attribute inside its quotes (`type=`, `role=`, `autocomplete=`, `target=`, `loading=`) and the modifiers after `|` on an event; `role` and `autocomplete` type their common words while any other still goes ([editor](editor-and-agent-commands.md)).
- `online()`, `pageVisible()`, `inView(options)` and `throttled(source, delay)` from `kay` give the connection, the tab's visibility, an element's presence in the viewport and a rate-limited value as reactive values; `elementSize().ref` and `inView().ref` let go of an element an `if` removes and take several ([Islands](islands.md#follow-the-connection-the-tab-and-the-scroll), [Effects](effects.md)).
- kayjs-auth: `account: { deleteAfter: '14d' }` gives a deleted account a grace period: `account.delete` marks it pending and mails a link to cancel, the user cancels from the `DeletionBanner` on the prebuilt pages (or `account.cancelDeletion()`), and the prune does the real deletion, `beforeDelete`, the audit log, `onEvent` and the account-deleted mail following it; off by default, and the Postgres table gains a nullable `delete_at` column ([grace period](../packages/auth/llms/passwords-and-mails.md#deleting-an-account-after-a-grace-period)).
- kayjs-auth: `linkedin`, `facebook`, `twitch`, `slack` and `x` join the OAuth presets, so `oauth: { x: true }` reads `X_CLIENT_ID` and `X_CLIENT_SECRET` and `kay env` lists them; X gives no email, and an `OAuthProvider` can set `clientAuth: 'basic'` for a token endpoint that wants an HTTP Basic header ([OAuth provider presets](../packages/auth/llms/oauth-providers.md)).
- kayjs-mail: components take per-use styling: `style` (appended last), the element's own attributes and `align` where it makes sense, `Button` takes `tone` (`accent`, `neutral`, `danger`), `block` and `target`, `Heading` and `Paragraph` take `tone`, `Image` takes `href`; the settings gain optional `danger` and `onDanger` colours, with dark equivalents derived or set through `dark`, and the Outlook fixes and the dark-mode classes still apply ([kayjs-mail](../packages/mail/llms/writing-and-sending.md)).
- `persisted` has one entry per storage, each with the options its storage takes: `persisted.cookie()` (which `persisted()` is), `persisted.local()`, `persisted.session()` (new, sessionStorage) and `persisted.query()`; `sync` reaches `local` and `session` through the `storage` event. `storage` of `persisted()` works until 1.104 and `kay upgrade` rewrites it ([persisted](islands-state-to-ids.md), upgrade line, `deprecated-persisted-storage`).
- `persisted` has one entry per storage, each with the options its storage takes: `persisted.cookie()` (which `persisted()` is), `persisted.local()`, `persisted.session()` (new, sessionStorage) and `persisted.query()`; `session` takes `sync` too, through the `storage` event, which a sessionStorage's tab shares with its frames only. `storage` of `persisted()` works until 1.104 and `kay upgrade` rewrites it ([persisted](islands-state-to-ids.md), upgrade line, `deprecated-persisted-storage`).

## 1.100.0

- kayjs-ui: a Dialog and a SidePanel take no `open` or `onOpenChange`: left out, each keeps its own state and a `@trigger(attributes)` block draws what opens it, like FormDialog; `open` still drives it and `closeHref` still works ([Dialog](../packages/ui/llms/basics.md)).
- kayjs-ui: a FormDialog takes no `open` or `onOpenChange`: left out, it keeps its own state and a `@trigger(attributes)` block draws what opens it, like ConfirmDelete; `open` still drives it ([FormDialog](../packages/ui/llms/forms-and-steps.md)).
- kayjs-ui: Combobox and MultiSelect take numbers as values like Select does: `onChange` hands back the option's own type, so a numeric id from a remote `options` stays a number, while the form posts its string; MultiSelect's `valueLabels` is keyed by that string ([pickers](../packages/ui/llms/pickers.md)).
- A rate limit answers its own 429: `await limit.enforce(ctx)` in a guard sets `Retry-After` and denies, the object `rateLimit()` returns goes to `protect: { rateLimit }`, `api({ rateLimit })` or `page.rateLimit` and counts with the guard, and `onLimit` on any limit is told of each request it refused ([Rate limits](rate-limits.md)).
- Event handlers take `|once`, `|self`, `|capture`, `|passive` and, on a key event, a key name (`onKeyDown|enter={send}`) beside `|preventDefault` and `|stopPropagation`, compiled into the handler so a page pays for those it writes ([Templates](templates-elements-slots-snippets.md)).
- The errors kay raises while serving a request that an app handles have a stable `code`, listed by `kay explain`: `error.code` on the error, `LogEntry.error.code`, the `kay.error.code` span attribute and `code` in the `observe.onError` event; a response failing its schema (`response-schema-mismatch`), an API answer kay cannot send, a refused redirect, a live value that cannot reach the browser and a closed store are among them; a refused redirect, a live value and an API answer kay cannot send are now `KayError`s, no longer `TypeError`s, and a response failing its schema is reported as a `KayError` named like Elysia's, its `cause` ([Errors](errors.md#errors)).
- kayjs-auth: the mails are written in the site's `i18n.locales` by default (English only before), the default locale first; `email.locales` still overrides it. kayjs-ui, kayjs-cms, kayjs-mail and kayjs-ai write their dates, times and sizes through `formatDate`, `formatNumber` and `sizeText`, so they follow the page's locale and `timeZone` (a chart's dates and file sizes, kayjs-cms's save times; the mail outbox sizes read `1.5 kB`). A dev tool module formats a time with `tool.time(at)` ([the dev tool](dev-tool.md#a-tab-for-a-library)).
- kayjs-auth: the mails are written in the site's `i18n.locales` by default (English only before), the default locale first; `email.locales` still overrides it. kayjs-ui, kayjs-cms, kayjs-mail and kayjs-ai write their dates, times and sizes through `formatDate`, `formatNumber` and `sizeText` of `kay/words` (the page's locale, light enough for every island), so they follow the page's locale and `timeZone` (a chart's dates and file sizes, kayjs-cms's save times; the mail outbox sizes read `1.5 kB`). A dev tool module formats a time with `tool.time(at)` ([the dev tool](dev-tool.md#a-tab-for-a-library)).
- kayjs-ui: Tabs and TabNav take `orientation="vertical"` (ArrowUp and ArrowDown); Tabs takes `activation="manual"` (arrows move the focus, Enter or Space shows the tab) and `lazy` (a panel is drawn on its tab's first showing); Carousel turns on a swipe and the arrow keys, takes `loop` and `perView`, and a slide needs no `src` or `alt` with a `@slide` block ([Tabs](../packages/ui/llms/tables-navigation-and-layout.md), [Carousel](../packages/ui/llms/charts-drag-and-media.md)).
- kayjs-ui: `await confirm({ message, title, tone, confirmLabel, cancelLabel })` asks from any handler and resolves a boolean, through the `ConfirmHost` that `ui()` mounts on every page (an `alertdialog`, focus on Cancel, Escape cancels); ConfirmDelete is its danger preset. Escape, a click outside and the close button of a Dialog or SidePanel with typed text ask "Discard changes?" with it instead of staying locked, `discard` wording the question and `discard={false}` keeping the lock ([confirm and ConfirmHost](../packages/ui/llms/toasts.md#confirm-and-confirmhost), upgrade line).
- `store()` tracks a `Map` or a `Set`, alone or inside a store object: `has(x)` and `get(x)` re-run only for `x`, `size`, iteration and the mutators behave as plain ones, and `snapshot` copies them; a `Date` stays untracked and a dev build warns once for one held in a store, or for a non-plain value given to `store()` ([State mutated in place](components.md#state-mutated-in-place)).
- `reactiveMap()` and `reactiveSet()` are a real `Map` and `Set` that track their reads and notify on their writes, `has(x)` and `get(x)` re-running only for `x`, and `snapshot` copies them to plain ones; `store()` keeps a Map, a Set or a Date as written and a dev build warns once for one it holds, naming the one to use ([State mutated in place](components.md#state-mutated-in-place)).
- A page or a layout takes `rateLimit` in `page` as an endpoint, an action or an API route does: `{ max, window, key? }` or a list, counted after the guards in `store.rates`, answering 429 with `Retry-After` through `_error.kay`; a layout's applies to each page under it, a page overriding it ([Rate limits](rate-limits.md)).
- kayjs-ui: a TreeView node takes `key` in place of `id`, and a Bell or BellInbox item takes `key`, `label` and `href` in place of `id`, `title` and `url`, the item shape of every other list; the old names work until 1.104 and `kay upgrade` rewrites them. kay's inbox answer and `notify()` keep `{ id, title, url }`, which the Bell maps ([upgrading](upgrading.md), [Bell and TreeView](../packages/ui/llms/page-layout-palette-and-trees.md)).
- Keys typed into a field before its island hydrated are also kept when the island hydrates late (`visible`, `idle`, a streamed block), a newer swap ends the wait, and number and email fields keep theirs, with no caret.
- One paging vocabulary: `limit` and `offset` for a window, `page`, `pages` and `pageSize` for numbered pages, `total` for the rows a result counts, and a cursor only where an API pages by one. kayjs-ui's `infiniteList()` takes `limit` in place of `pageSize`, and `collectionInfo()` reports `total` in place of `count` ([conventions](component-library-conventions.md#conventions), [Infinite list](../packages/ui/llms/infinite-list.md)).
- `hydrate="interaction"` hydrates an island on the first pointer, focus, key or touch event inside it, and `hydrate="media(max-width: 40rem)"` once the media query matches, now or later; a `visible` island with no box, every child `display: none`, is watched through its parent too ([When to hydrate](islands.md#hydrate-an-island-later)).
- A page waits for every `await` of its server fence, so one slow load makes every click on it wait. [Caching and streaming](rendering.md) opens with the rule (await only what the first paint needs, start the rest unawaited for an `await` block, cache what is shared) and so does `kay new`'s AGENTS.md; the `serial-awaits` lint (`performance` group, `warn`) finds consecutive independent `const x = await ...` statements and offers one `Promise.all` as an unsafe fix, since a guard must stay first ([lints](lints.md)); in development a page whose loads pass `observe.loadBudget` (`'300ms'` by default, `false` for none) is warned of in the terminal, the browser console and the dev tool's Request tab, naming the slowest load ([Tracing and timing](tracing.md#tracing-and-timing), [dev tool](dev-tool.md)).
- `resetEachTest(clear)` of `kay/test` clears a library's fake or outbox before and after every test, as `mailTest(site)` and `aiTest()` do; and `cmsTest(site)` has `signInWith(password)` beside `signInAs(role)` and `signOut()`, replacing `cmsSignInAs`, `cmsSignInWith` and `cmsSignOut`, so signing in and out reads the same in kayjs-auth and kayjs-cms ([testing](testing.md)).
- A page waits for every `await` of its server fence, so one slow load makes every click on it wait. [Caching and streaming](rendering.md) opens with the rule (await only what the first paint needs, start the rest unawaited for an `await` block, cache what is shared) and so does `kay new`'s AGENTS.md; the `serial-awaits` lint (`performance` group, `warn`) finds consecutive independent `const x = await ...` statements and offers one `Promise.all` as an unsafe fix, since a guard must stay first ([lints](lints.md)); in development a page whose loads pass `observe.loadBudget` (`'300ms'` by default, `false` for none) is warned of in the terminal, the browser console and the dev tool's Request tab, naming the slowest load, and a layout whose load outlasts the page's own loads gets its own warning naming the layout file and both times ([Tracing and timing](tracing.md#tracing-and-timing), [dev tool](dev-tool.md)).

## 1.99.0

- Keys typed into a text field a page swap just brought in, before its island hydrated, are kept and reach the island as an `input` event, the caret after them; a field that writes its parent's value back as it hydrates no longer drops them.
- `observe.serverTiming` also covers actions, endpoints and API routes, which send `Server-Timing` with their guards and handler, and the spans an API handler starts nest under its request's, in a `kay.handler` span ([Tracing and timing](tracing.md#tracing-and-timing)).
- Every public DOM event is `<lib>:<verb>` on `document` with an object `detail`: `kay:renew`, `kay:install`, `kay:dev-built`, `kay:dev-types`, `kai:chat-open`, `kai:chat-send`, `kai:chat-draft` and `kui:hold-defaults`; the old names fire too until 1.103, and `deprecated-event-names` finds what `kay check` can read, with a fix where the handler changes nothing else. Cookies are `kay_<name>` and storage keys `<lib>:<name>`, in one [table of events and the two rules](events.md).
- `analytics()` and `vitals()` take `awaitConsent` in place of `consent`, which now names only the visitor's answer; kayjs-ai's `ask()` takes `effort` and `approval` in place of `reasoning` and `confirm`, and `Chat` takes `showReasoning` and `waitingLabel` in place of `reasoning` and `thinkingLabel`. The old names keep working and `kay upgrade` renames them ([analytics](analytics.md), [upgrading](upgrading.md)).
- kayjs-cms: the form layout of a collection takes `exclude` in place of `hide`, so a list of what to leave out is spelled the same in every library ([Arranging and replacing the screens](../packages/cms/llms/screens.md)).
- kayjs-ui: MarkdownEditor takes `previewHtml`, the preview of its starting text drawn by the server and kept until an edit, so a page opened with `previewing` loads rendered instead of empty ([MarkdownEditor](../packages/ui/llms/markdown-editor.md)).
- kayjs-ui: the items of a Timeline, Accordion, MediaGallery, AppSwitcher and AudioPlayer take the names every list item has, `{ key, label, description?, href?, icon?, tone?, disabled? }` with `value` only for a form value: `text`, `value`, `title`, `id` and `url` become `label`, `key` and `href`, the old names working until 1.103 ([one item shape](../packages/ui/llms/slots-and-links.md), upgrade line, `deprecated-ui-items`).
- kayjs-ui: a RowsField `@cell` is drawn once per row and keeps its control when a row above it is removed or added; its `index` is now a function, `index()`, so the cell's name follows the row ([RowsField](../packages/ui/llms/forms.md), upgrade line in [upgrading](upgrading.md)).
- Keys typed into a search field a page swap just brought in, before its island hydrated, are kept and reach the island as an `input` event, the caret after them; a field that writes its parent's value back as it hydrates no longer drops them.

Releases before 1.99 are in [What's new, older releases](whats-new-archive.md).
