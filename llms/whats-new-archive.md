# What's new, older releases

What each release before 1.83 added, and the end of a newest release that was cut short (`(continued)`), newest first, each feature with where it is documented. The newer releases are in [What's new](whats-new.md); what a release breaks is in [Upgrading](upgrading.md).

## 1.82.0

- An extension's API module may default-export a function of the `ExtensionApp`, called with the `appFiles` modules as a `server` function is, so a library serves the app's data file, `api({ cors })` included, and the app writes no module only forwarding it; an island hands such a module to `call()`, `socket()`, `stream()` or `resource()`, typed off the routes it builds: [Component libraries](component-libraries.md).
- An action's stream is read to its end with `await answer.ended()`, resolving with its last value and rejecting when it failed or was closed, with no polling of `status()`: [streaming actions](actions-from-islands.md).
- A production page that posts forms and holds no island loads the navigation-only entry alone, which `kay build`'s route sizes and size report weigh it with, and an island page loads the forms' listener only once it shows a form: [building](build-and-start.md#build-and-start-commands).
- A form posted before the forms' listener loaded is held only when the swap would take it and posted once, a post the swap leaves out going to the browser untouched, and a form holding a control named `enctype`, `elements`, `style`, `noValidate`, `requestSubmit` or `reportValidity` is checked, posted and refused as one without it, a multipart one posting multipart again.
- `site.open()` serves a `testSite()` with a `base` under it, so a browser test needs no front of its own, and `kay screenshot` and `kay a11y` pipe a page's websockets under a base too; `testSite()` rebuilds its islands when any file the build read changes (`kay.config.ts`, `public/`, content, libraries) and keeps them when one it did not read changes, a file the root `.gitignore` leaves out included: [Testing in a browser](testing-browser.md), [testing](testing-setup.md).
- A page reading `window['scrollTo']`, or a parameter or import named like `Date` or `fetch`, is now kept, and one reading an exported constant is no longer refused because a string, a comment, an object key or a template's tag shares its name: [prerendering](prerendering.md).
- A rate limit whose store throws, rejects or hangs counts in memory instead, logged once, for an action's limits, API routes, `rateLimit()` and proof of work as for kay's own routes, and the MCP endpoint's 429 says how long to wait: [Rate limits](rate-limits.md#reference).
- kayjs-ui: `RecordButton` records the microphone into a File, owning permissions, busy state and device release, and kayjs-ai's `Chat(transcribe={transcribe})` adds a microphone beside the field that sends what the action writes down: [RecordButton](../packages/ui/llms/basics.md#recordbutton), [Chat](../packages/ai/llms/chat.md#speaking-a-message).
- kayjs-ui: a `SaveForm`, `FormDialog` or submitting `Select` whose form holds a control named `elements`, `requestSubmit` or `reset` saves, submits and discards instead of throwing.
- kayjs-auth: the methods of a feature are grouped under it, `auth.admin.listUsers()`, `auth.password.signIn(input)`, so an editor lists one feature's methods at a time; the flat names work until 1.85, and `kay upgrade` renames the calls: [Grouped methods](../packages/auth/llms/grouped-methods.md).
- kayjs-auth: attempts count in memory, logged once, while the store's `rates` throws, rejects or takes over 8 s, so a sign-in still answers and still locks out: [Limits](../packages/auth/llms/hardening-and-testing.md#limits).
- kayjs-ai: `Chat`'s `keepOnServer` has the server keep the conversation through the action's own `ask`, a reload or Back showing it again under `?conversation=`, `conversations` lists the visitor's with rename and delete, a reply of an `outlive` ask is picked back up after a reload, and a tab whose reply lost its write to another tab is refused with 409: [Conversations kept on the server](../packages/ai/llms/chat-conversations.md).
- kayjs-ai: `ChatLauncher` takes `keepOnServer` and `conversations`, the panel's conversation named by this browser through `Chat`'s new `conversationIn="browser"`, so a reload, another page or a new tab shows it again: [A chat on every page](../packages/ai/llms/chat-conversations.md#a-chat-on-every-page).
- kayjs-ai: an approval ticket whose store fails or takes over 5 s runs no call, where a hanging store held the reply: [Actions as tools](../packages/ai/llms/tools.md).

## 1.81.0

- kayjs-ui: `RowsField` is a repeatable rows field, a box per column with Add and Remove, in a signal editor, a form posting to an action or a `SaveForm`: [RowsField](../packages/ui/llms/forms.md#rowsfield).
- kayjs-ui: `infiniteList(first, { action, input, failure })` pages through an action, `pageFields` and `pageOf` give the action its paging, and `patch(id, change)` updates one loaded row: [Infinite lists](../packages/ui/llms/infinite-list.md).
- kayjs-ui: a Table over a `list` sends its search text and its `fields` to the list's `load` as `filter`, kept in the URL, and `list.filterBy` and `list.restart` do the same from code: [Infinite lists](../packages/ui/llms/infinite-list.md).
- kayjs-ui: `SaveForm` takes `cancelHref` for a Cancel link, `confirm` for a question before saving and `saveDisabled` to keep Save off with its reason: [Forms](../packages/ui/llms/forms-and-steps.md).
- kayjs-ui: `attempt(run, { failure, onRefused(data) })` hands a refusal to the app instead of toasting it: [Toasts](../packages/ui/llms/basics.md).
- kayjs-ui: `Select` and `Segmented` take `param` (with `paramDefault`) to hold a query param of the page with no island of the app's: [tables](../packages/ui/llms/tables-navigation-and-layout.md).
- kayjs-ui: `TabNav(tabs param="tab")` builds its links from a query param and marks the current tab, a link taking `prefix` or `also` to stay current on sub-pages: [tables](../packages/ui/llms/tables-navigation-and-layout.md).
- kayjs-ui: `DateTimeInput` shows a date and time on the visitor's clock and posts the instant with its offset, which `s.Date()` reads: [forms](../packages/ui/llms/forms.md).
- kayjs-ui: the `kui-prose` class styles running text you did not template, such as `markdownHtml` or `sanitizeHtml` output: [forms](../packages/ui/llms/forms.md).
- `withQuery({ page: 2, sort: null })` from `kay` gives the current page's path with those query params set or dropped, following the address in an island: [Navigating from code](navigation-from-code.md#navigating-from-code).
- A page's `query` field with `lenient: true` reads a value its schema refuses as its default instead of answering 400: [Routing](routing.md#reference).
- `mediaQuery('(...)')` and `reducedMotion()` from `kay` follow a media query or `prefers-reduced-motion` in an island, the server rendering a stated fallback: [Follow a media query](islands.md#follow-a-media-query).
- `timeZone` in kay.config.ts sets the zone dates are written in, on the server and in islands, and `kay/i18n` has `formatBytes` and `formatDuration`: [Locales](locales.md#helpers).
- `cached(key, ttl, load, { stale: false })` waits for a fresh load past its ttl, and `{ fallback }` answers a value when the first load throws; `cache()` takes both: [Caching](rendering.md#caching).
- `s.UnionEnum(values)` no longer defaults to its first value, so a field that wants one passes `{ default }`: [Actions](actions.md).
- `s.File` and `s.Files` take `minSize` and `maxSize` as `'2mb'`, and an action with no `maxSize` takes what its file fields add up to, ten files for an `s.Files` without `maxItems`: [Files posted to an action](files.md#files-posted-to-an-action).
- A string `defineEnv` field also reads `<NAME>_FILE`, a file holding its value, as a compose secret hands it: [Environment](environment.md#environment).
- `basicAuth({ user, password, realm })` from `kay/server` is a `_guard.ts` for HTTP Basic, refusing every request while the credentials are unset: [Guards](server.md#basic-auth).
- `kay build` and `kay dev` build an app in a workspace on Bun's isolated linker, so `linker = "hoisted"` in `bunfig.toml` is no longer needed: [Component libraries](component-libraries.md).
- `kay build` prerenders up to 8 of a route's pages at once: [Prerendering](prerendering.md#prerendering).
- `compressionDictionary: false` in kay.config.ts builds no compression dictionary, and a rebuild compresses again only the pages that changed: [Compression](proxy-and-security.md#compression).
- kayjs-ai: `ask(messages, { sources })` has a reply cite documents as `[n]`, which `Chat` links and lists under the turn: [Chat sources](../packages/ai/llms/chat-sources.md).
- kayjs-ai: `chatMessages({ maxItems, maxLength, attachments })` is the schema of the history a `Chat` posts, and `lastChatMessage(messages)` reads the one just sent: [Chat](../packages/ai/llms/chat.md).
- kayjs-ai: `ChatTurn` is the type of `Chat`'s `initial`, `{ role, content, sources? }`: [Chat](../packages/ai/llms/chat.md#props).
- kayjs-ai: `tool: { label }` on an action, or `label` on a `tool()`, words its calls in `Chat`, and `kay check` warns (`unknown-tool-label`) of a `toolLabels` key naming no tool: [Actions as tools](../packages/ai/llms/tools.md), [Chat](../packages/ai/llms/chat.md).
- kayjs-ai: `await reply.steps` lists the model requests a reply made, with their timing, usage and tool calls, and a finished `ToolCall` has `ms`: [Asking](../packages/ai/llms/asking.md).
- kayjs-auth: a store of the app's own needs no `attempts`, which count in the app's `store.rates` or the store's `rates`, `DEFAULT_LIMITS` writes its windows as durations, and kay's `RateStore` gains an optional `reset(key)`: [Limits](../packages/auth/llms/hardening-and-testing.md#limits).
- kayjs-auth: `forwardAuth` sets the session cookie on the visited host's domain with no `domain` on `session()`, naming it `kay_session` so its users sign in once more, and `auth({ cookie })` names the cookie: [Guarding other sites](../packages/auth/llms/oauth-server-and-tokens.md).
- kayjs-mail: bounces and complaints have a store of their own, `mailer({ suppressionStore: pgSuppressions(db) })` keeping them in Postgres, so a mailer with no list opens no list store: [Bounces and replies](../packages/mail/llms/bounces-and-replies.md).
- A component mounted by `mountComponent` has `type`, `click` and `press` firing a browser's events, and `setProps` giving it new props as a parent would: [Mounting a component](testing.md#mounting-a-component).
- `site.logs` in `kay/test` lists what the server logged during the test: [Read the log](testing.md#read-the-log).
- `waitUntil(condition, { timeout, what })` from `kay/test` polls a condition in a server test and fails naming what it waited for: [Testing requests, jobs and sockets](testing-requests-jobs-sockets.md).
- `memoryJobs()` lists a queue's jobs by when they are due, as `sqliteJobs` and `pgJobs` do: [Queues](queues.md#reference).
- An action call takes `undefined` on an `s.Optional` field, reports a wrong field at that field, and `Parameters<typeof add>[0]` reads its typed input: [Calling from an island](actions-from-islands.md#calling-from-an-island).
- `kay check` reads an icon from an imported object of `~icons/` imports, and a list built from it, as data, so such a component no longer renders as an island: [Islands](islands.md).
- A library linked from its own folder with kay as a dev dependency shares the app's kay, so its `api()` is served: [Component libraries](component-libraries.md).
- A page following a cached value or a live `resource()` refreshes behind a proxy rewriting the live stream's line breaks to `\r\n`: [Following cached values](live-values.md#following-cached-values).
- `queue(name, handler, { live: true })` lets an island follow the queue's waiting and running jobs with `jobs(name)` from `kay`, across workers and replicas: [Show a queue's jobs on a page](queues.md#show-a-queues-jobs-on-a-page).
- A page whose only `Date`, `fetch`, `process`, `Bun` or `ctx` sits in a comment, a string, a type or the template's text, or which imports only types from `kay`, is now [kept](prerendering.md).

## 1.80.0

- `formatNumber`, `formatDate`, `formatRelativeTime`, `formatList` and `direction` from `kay/i18n` work outside a request, in the site's default locale, so a job, an alert or a push formats like its pages, and each takes a `locale` option (`formatDate(date, { locale: user.locale })`) that wins over the page's, in the browser too: [Format a number, a date or a list](locales.md#format-a-number-a-date-or-a-list).
- `promoted-island` no longer reports a static component for a value read from an object of strings or numbers another module exports as a literal (`LABEL[kind]`), by name, in `export { LABEL }`, by default, re-exported or imported from a `.json` file, as it is data and not a function: [Islands](islands.md#islands).
- `fakeService(routes)` from `kay/test` stands in for an outside HTTP service: a real loopback server whose `url` feeds `overrideEnv`, that records its `requests`, answers errors with `fail(status)` and holds requests with `stall()`, and stops with the test file, so no test hand-rolls a `Bun.serve` fake or a `fetch` spy: [Testing](testing.md#test-an-app-calling-an-outside-api).
- `testSite({ proxyKey })` checks the `proxy.key` header for that site alone and sends the key with every request, so a test of an app behind a proxy writes no `KAY_PROXY_KEY`: [Testing](testing.md).
- kayjs-ui has a `RelativeTime(date)`: a `time` worded relative to now in the page's locale (`3 hours ago`), ticking in the browser and hydrating the text the server drew, with the full date as a tooltip reachable by keyboard: [basics](../packages/ui/llms/basics.md).
- kayjs-ui has a `Tooltip(text="...")` wrapping text in a tab stop that `TooltipHost` shows the tooltip of, so no hand `tabindex="0"` is needed, and a `Button` that is `disabled` with a `data-tooltip` renders `aria-disabled` instead, staying focusable to read its reason while ignoring its press. `kay check --fix` rewrites a hand-written `span(data-tooltip tabindex="0")` to `Tooltip` (`hand-tooltip`): [basics](../packages/ui/llms/basics.md#popover-hovercard-tooltiphost).
- `sanitizeHtml(markup, { base })` resolves the relative URLs of markup fetched from elsewhere against its address, and the links it keeps that leave your site open in a new tab, like a template's: [Templates](templates-elements-slots-snippets.md).
- `mcp: { key }` requires a bearer key on the MCP endpoint and so on its tool calls, from `KAY_MCP_KEY` or `KAY_MCP_KEY_FILE` (`key: true`), a string, or `{ file }` made on first use, compared in constant time; with `proxy.key` the endpoint needs no `proxy.open` entry and no app guard, `kay env` lists the variables, and `testSite({ mcpKey })` sends the key from `site.mcp`: [API routes](api-routes.md#mcp).
- A module an island imports may build schemas with `s` as it loads: in the browser `s` builds an inert stand-in with no validator, so a type and its schema live in one module shared with the server, and `server-only-in-island` no longer refuses `s`, only `process` and `Bun` reads: [Schemas](schemas.md#schemas).
- kayjs-ai: `ask` outside a request takes `tool({ name, description, input, run })` functions as `tools`, run with the app's own rights and never held for approval, so a scheduled job's model can call things: [Function tools](../packages/ai/llms/tools.md#function-tools).
- kayjs-ui has an `AudioPlayer`: chapters on a timeline and in a list, a timed transcript following the playback, lock screen controls skipping between chapters, an `@actions` slot per chapter and a readable position ([Charts, drag and drop and media](../packages/ui/llms/charts-drag-and-media.md)).
- kayjs-ai `reasoning` now works on `anthropic()`, as adaptive thinking at that effort (`'none'` asks the lowest effort with thinking off), what the model thinks streams as `reasoning` in `reply.progress()` for Anthropic and OpenAI-compatible servers without touching `await reply`, tool loops send Anthropic's thinking blocks back, and `Chat` folds it above the reply, `reasoning={false}` hiding it: [asking](../packages/ai/llms/asking.md#ask-options), [chat](../packages/ai/llms/chat.md#props).
- kayjs-ai `ask(..., { body })`, and `openai({ body })` and `anthropic({ body })` for every ask of a provider, add fields kayjs-ai does not model (`top_p`, `seed`, `stop`, `top_k`, OpenRouter's `provider`) to the request body, so a new provider parameter needs no release: [asking](../packages/ai/llms/asking.md#fields-kayjs-ai-does-not-model).
- kayjs-ai: a user message holds `attachments`, images and PDFs from a `File`, `Blob`, bytes or a stored file, sent as each provider expects and readable into a `schema`, with `maxAttachmentBytes`, a price in characters against `maxInputChars` and an `unsupported` error; `Chat` takes `attach` with the upload's type and size checks; the fake records them in `asked`: [Images and PDFs](../packages/ai/llms/attachments.md), [Chat](../packages/ai/llms/chat.md#attaching-files).
- kayjs-ai: `Chat(regenerate)` asks again for the last reply and `Chat(editable)` resends an edited message with every later turn gone, and an action reads `replaces()` to drop the stored turns they replace; kayjs-ui has `refresh` and `edit` icon slots: [chat](../packages/ai/llms/chat.md#regenerating-and-editing).
- kayjs-ai: `Chat(fill)` takes the height of its container, the log (or the greeting) taking the space and the form staying at the bottom, for a chat that is a page's main content: [chat](../packages/ai/llms/chat.md#props).
- `kay check` reports `signal-set-call`, a signal written `count.set(value)` where assigning it, `count = value`, does the same, and `--fix` assigns it: [Signals](components.md#signals).

Releases before 1.80 are in the notes of their releases, at https://git.kaynooo.fr/kaynooo/kayjs/releases.
