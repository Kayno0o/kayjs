# What's new

What each release of kay and its libraries adds, newest first, each feature with where it is documented. kay and its libraries share one version, so one section covers them all; what a release breaks is in [Upgrading](upgrading.md).

## Unreleased

- An island hears kay's DOM events through function hooks: `navigation.onStart`, `onError` and `onStall` beside `onNavigate`, and `add.onStart`, `onData` and `onError` on an action for the forms posting it in place, one table mapping each event to its hook ([events](events.md), [navigation](navigation-from-code.md#navigation-state-and-hooks), [actions](actions-from-islands.md)). The events stay for a plain script, `guardLeave` is documented as the preset of `navigation.onBeforeNavigate`, and `deprecated-island-events` reports an island's `listen` of an event and rewrites the swap's.
- `kay check` names the unknown id of a lone `T('nope')` (`T` has no message `nope`) instead of asking for the values of a message that does not exist ([Texts](locales.md#messages-holding-markup))

- `guards` on a page, a layout, an endpoint and an `api()` module takes a guard, a list or `{ load }` as well as `false`: `false` skips the guards above, a list runs after them, and a route with guards of its own is covered ([Guards](guards.md)).
- The config's hooks are flat keys named by the moment they run, `onListen`, `onStop` and `onError` (which left `observe`), every hook event carries one `context` (an action hook's holds the action's own context too), `observe.log` is `{ format, requests, sink }`, and `pages()` and `testSite()` take their config as `{ config }` beside `root`; `deprecated-app-hooks`, `deprecated-hook-context` and `deprecated-pages-options` rewrite the old forms ([Hooks](hooks.md), [Production](production.md), [Project](project.md)).
- `images` is grouped as `remote: { hosts, maxSize, timeout }`, `formats: { quality, webp, avif }` and `limits: { variants, queue }`, and the lists a CMS or a database may hold take a function returning them (or a promise): `cors.origins`, `security.hosts`, `images.remote` hosts, `proxy.trusted`, `redirects`, `robots.disallow` and `allow`, `i18n.paths`, called once as the config loads; `ttl` is how long `signed.sign()`, `files.url()` and an action's `minTime` and `proofOfWork` keep what they made, `maxAge` staying for HTTP and cookies, and `deprecated-images-keys` and `deprecated-ttl-names` rewrite the old names ([Project](project.md), [Images](images.md)).
- `images` is grouped as `remote: { hosts, maxSize, timeout }`, `formats: { quality, webp, avif }` and `limits: { variants, queue }`, and the lists a CMS or a database may hold take a function returning them (or a promise): `cors.origins`, `security.hosts`, `images.remote` hosts, `proxy.trusted`, `redirects`, `robots.disallow` and `allow`, `i18n.paths`, called once as the config loads; `ttl` is how long `signed.sign()`, `files.url()`, `workChallenge()`, kayjs-auth's `proofOfWork()` and an action's `minTime` and `proofOfWork` keep what they made, `maxAge` staying for HTTP and cookies, a store takes every length as a `Duration` (`durations: true`, [Stores](stores.md); a store written before keeps getting milliseconds until 1.108), and `deprecated-images-keys`, `deprecated-ttl-names` and `deprecated-store-ms` rewrite the old names ([Project](project.md), [Images](images.md)).

- A page with `liveRefresh: true` in its settings is left to its live connection after a call whose handler invalidated only cached keys it follows, instead of loading again; `resource(..., { revalidate: 'focus', stale: '30s' })` leaves an answer be for its stale window on focus and reconnect ([actions from islands](actions-from-islands.md), [API from islands](api-from-islands.md)).
- A page with `liveRefresh: true` in its settings is left to its live connection after a call whose handler invalidated only cached keys it follows, a streaming action's included (its end event names them), instead of loading again; `resource()` refetches when a tag its route's cached value names is invalidated, even once memory dropped that value, `revalidate: 'focus'` with `stale: '30s'` leaves an answer be for its window, and without `revalidate` a resource asks again only for `refresh()`, an invalidation or a changed option ([actions from islands](actions-from-islands.md), [API from islands](api-from-islands.md)).
- Every feature key of `kay.config.ts` takes `false`, `true` or its options (`robots`, `sitemap`, `favicon`, `security`, `health`, `preview`, `images.avif` and the rest), and `defineConfig` refuses an unknown key in every option bag at any depth, derived from `KayConfig` itself; `proxy: 2` is `proxy: { hops: 2 }`, which `deprecated-config-switch` rewrites ([Project](project.md)).
- The server hooks of kayjs-auth, -mail, -cms and -ai that observe are `after<Verb>`, as `before<Verb>` is the one that may refuse or change: `afterSignUp`, `afterSend`, `afterSuppress`, a list's `afterSubscribe`, `afterConfirm`, `afterUnsubscribe` and `afterBroadcast`, `afterSave` and `afterUpload`, `afterStep`, `afterToolCall` and `afterRequest`. The old `on<Verb>` names work until 1.108 and `deprecated-hook-names` renames them; see [Hooks](hooks.md) and [Upgrading](upgrading.md).
- Every island source reads and reports the same way: `data()`, `status()`, `pending()`, `error()` and `retry()`, with `onData({ value })` and `onError`, on a `resource`, a `stream`, a `socket`, a `local()` collection and a `track()` handle (`data()` and `status()` on an action too), one `LoadStatus` for reads and one `ConnectionStatus` for connections ([island sources](island-sources.md)). A collection's sync moves under `sync` (`sync.status()`, `sync.queued()`, `sync()`), and `pending()` and `status()` mean what they do everywhere ([local collections](local-collections.md)). `value()`, `last()`, `rows()`, `succeeded()`, `onSuccess` and `onSync` work until 1.108, and `deprecated-source-readers` rewrites them.
- Live values and presence write alike: `live(initial, { key: true })` declares a value per key with a plain starting value, `set(next, { key })` and `set(next, { user })` write one key's or one user's, `presence({ room, member })` takes one object, and every live value tells `onData({ value })` and `onError({ error })` in a browser; `deprecated-live-api` rewrites the old forms ([live values](live-values.md), [island sources](island-sources.md)).
- One `Action` type crosses into components: bare `Action` takes any action, and a `.with()` action crosses into an island with its fields (`Action<never, unknown>` is rewritten by `deprecated-action-type`) ([actions from islands](actions-from-islands.md#pass-an-action-to-a-component)).
- Every component callback takes one event object and one naming rule: `onOpenChange({ open })`, `onChange({ value, option })`, `onSelectedChange({ keys, rows })`; state a prop can hold reports through `on<Prop>Change`, a press through `on<Verb>`, and `tests/callbacks.test.ts` holds the rule. `onChange` of Accordion, Tabs and ThemeToggle is `onValueChange`, ZoomPane's `onPlateChange`, Table's `onSortChange` and a chart's `onActiveChange`, the old names working until 1.108 with a `deprecated-ui-callbacks` fix ([conventions](component-library-conventions.md), [upgrading](upgrading.md)).
- Every guard option is named `guards` and takes a guard, a list, `{ load }` or `false`: `vitals({ guards })`, `jobs: { guards }`, `images: { guards }`, beside a page's and an API module's. A feature that lists or changes private data (`jobs`, `images.resolve`) answers 403 with none, and `requireGuards` is `guards: { default: 'closed' | 'open' }` ([Guards](guards.md#path-and-guard-options)); `kay check --fix` rewrites the old forms.
- Rate limits are one `RateLimit` and one check: `rateLimit(name, limit).check(ctx)` refuses a guard's request with a 429 (`enforce` is deprecated for it) and `.count(request)` gives `{ count, resetAt, wait }`; kayjs-auth's `rateLimit` is grouped by feature (`signIn: { ip, account, accountAll }`, `oauth: { token }`); `deprecated-rate-enforce` and `deprecated-auth-rate-limits` rewrite the old forms, and each kind of route's counting phase is written down ([Rate limits](rate-limits.md#when-a-request-is-counted)).
- `images.rateLimit`, `mcp.rateLimit`, `live.rateLimit` and `basicAuth({ rateLimit })` take a whole `RateLimit` minus `key`: a `store` to count in and an `onLimit` told of each refused request, as an action's does ([Rate limits](rate-limits.md#in-the-libraries)).
- A form names a field once: `FormField(field="title")` names the bare `input` in it and gives it the schema's constraints, `label(field="name")` writes the label's `for` and the control's `id`, and `button(action={x})` outside a form posts by itself, on a static page and in an island ([forms](actions.md#name-a-field-once)).
- The page flags `keep`, `reload`, `layouts` and `guards` are plain booleans in `page`, an endpoint and an `api()` module (`guards: true` says what the default does), where each took one literal before ([Routing](routing.md#page-settings)).
- An island declares its settings in one place: `island({ render, hydrate, persist, interactive })` first in its script, as it declares its props, replaces the `--- island`, `--- client` and `--- static` fence lines and `export const island`; a use writes `render="client"` for `hydrate="client"` and `server defer` for `server="defer"`. `kay upgrade` rewrites the old forms, which work until 1.108 ([Islands](islands.md#islands)).

## 1.104.3

- `kay new` writes no `.npmrc`: kay and every package a preset installs (`@kaynooo/eslint`, `@kaynooo/pg-orm`, `@kaynooo/utils`) are on npm, and kay depends on `@kaynooo/cli-kit` 0.46.1, a version npm carries, so a project installs with Bun's defaults and the install pages have no registry step; the generated `Dockerfile` copies `package.json` and the lockfile alone, and an existing project's `.npmrc` stays harmless ([project setup](project-new-and-add.md)).
- A compiled component is smaller: a prop whose default is a literal (a string, number, boolean, `null`, a template with no expression) is written where the prop is read, with no holder, and a branch holding one component compiles to one call; an object, array or function default keeps its holder, so its identity holds across reads ([props](components.md)).
- kayjs-ui: `starfield` works without the space skin and in light mode: `@import '@kayjs/ui/starfield.css'` after the theme, `class="starfield"` on `body`; the dots (eleven, three tints, scattered where `random()` works) read `--color-star`, `--color-star-cool` and `--color-star-warm`, white by night and ink by day, and `kay new`'s starter uses it ([Setup](../packages/ui/llms/setup.md)).
- kayjs-ui: the space skin's sky is now orbit's, denser and in three tints, and `starfield` works without the skin and in light mode: `@import '@kayjs/ui/starfield.css'` after the theme, `class="starfield"` on `body`; the dots (eleven, three tints, scattered where `random()` works) read `--color-star`, `--color-star-cool` and `--color-star-warm`, white by night and ink by day, and `kay new`'s starter uses it ([Setup](../packages/ui/llms/setup.md)).
- `kay upgrade` adds to `devDependencies` the optional peers the app had installed without declaring them (`typescript7`, `axe-core`, `@happy-dom/global-registrator`, `@kaynooo/pg-orm`), at the new kay's range, in text, under `--dry-run` and as `changed` under `--format json` ([kay upgrade](check-and-tools.md)).
- `kay upgrade` warns when it raises a dependency the app shares with kay across a major (a 0.x minor counts), naming the versions and the package's migration file or repository, in text and as `warnings` under `--format json` ([kay upgrade](check-and-tools.md)).
- kayjs-ui: a Meter and a Progress draw their track `surface-strong`, so the unfilled part reads inside a Card or any `bg-surface` box; Toggle's frame, Slider's and AudioPlayer's range track already read at 3:1, and a test holds every track on the background, surface and popover in both schemes and each skin ([Setup](../packages/ui/llms/setup.md)).
- `kay new` starts from orbit's look: kayjs-ui's space skin (the `ui` feature, now in every preset, with `AppHeader`, Space Grotesk and JetBrains Mono through `fonts`), a near-black palette named as kayjs-ui names it (`background`, `foreground`, `border`, `muted`), a starfield behind the page, a hairline on every box, and an accent picker of twelve accents; the palette no longer defines `--color-base`, which made `text-base` paint text the page background ([kay new](project-new-and-add.md)).
- kayjs-ui's `AppHeader` and `SiteNav` are islands only in a use that sets `open`, `onOpenChange` or `link`, so a header with none of them is markup and its menu the browser's popover, with no script of its own ([kayjs-ui](../packages/ui/llms/tables-navigation-and-layout.md)).
- The `text-size-colour` lint reports `text-base` (or another size) in an app whose CSS defines a colour of the same name, such as `--color-base`, where the utility is the font size and the text colour at once ([code lints](code-lints.md)).
- `kay lint --fix` leaves no semicolon in a `.kay` fence: a fix that rewrites code up to the next token (`style/semi` after the `import type` split of `import/consistent-type-specifier-style`) is cut down to what it changes, so it applies instead of being dropped.
- A component reading a `persisted` value (`local`, `session`, `cookie` or `query`) imported from a `.ts` module is an island, as one reading a `live` value is, also when the module re-exports it (`export { x } from`, `export *`) or imports it and exposes it; `kay explain island` says so: [Islands](islands.md).
- A component reading a `persisted` value (`local`, `session`, `cookie` or `query`) imported from a `.ts` module is an island, as one reading a `live` value is, also when the module re-exports it (`export { x } from`, `export *`) or imports it and exposes it (a `live` value or a `signal` reached that way is now found too); `kay explain island` says so: [Islands](islands.md).
- `waitFor(selector, { text })` in a browser test matches a French page's text typed with plain spaces, where kay wrote non-breaking ones (U+00A0, U+202F), and a timeout says when an element holds the text up to its whitespace: [Browser tests](testing-browser.md).
- kayjs-ui: `Meter(segments={[{ value: 5, tone: 'success', label: 'known' }, ...]} max={22})` draws parts of one total end to end, each a `fill` part, and screen readers hear each one ([Meter](../packages/ui/llms/basics.md)).
- A utility a recipe lifts has one rule, in `utilities.recipe`: Tailwind no longer also writes it in `utilities` unless a file, a word of the build or an `@source inline` names it too ([styles](styles-and-assets.md)).
